## 创建 Agent

`CodingAgent` 是执行对象；Session 只决定新建、恢复或临时持久化方式。

```ts
import { createCodingAgent, type CodingAgentHost } from "@jai/coding-agent";

const host: CodingAgentHost = {
  model: {
    resolve: async ({ model, settings }) => {
      // 宿主在这里用自己的凭据与配置解析真实 Model / Provider。
      return { model: resolvedModel, provider: resolvedProvider };
    },
  },
  workspace: { cwd: process.cwd(), trusted: true },
  session: { directory: ".jai/sessions" },
  approval: {
    request: async () => "allowOnce",
  },
};

const created = await createCodingAgent({
  host,
  session: { kind: "new", persistence: "durable" },
  execution: { permissionMode: "default" },
});
if (created.isErr()) throw new Error(created.error.message);

const agent = created.value;
const result = await agent.prompt({ prompt: "修复登录测试" });
if (result.isErr()) throw new Error(result.error.message);

await agent.close();
```

## Session 选择

| 选择 | 行为 |
| --- | --- |
| `{ kind: "new", persistence: "durable" }` | 创建 durable Session；同 id 已存在时返回 typed error。 |
| `{ kind: "resume", id }` | 只恢复已存在的 Session；不存在时绝不自动创建。 |
| `{ kind: "ephemeral" }` | 创建进程临时 Session，并在 `close()` 后清理。 |

## Agent 生命周期

`prompt()` 会在 Agent 的 serialized execution drain 中执行。`steer()` 将输入插入当前执行中的下一处安全边界；`followUp()` 则在当前执行结束后继续。`abort()` 仅停止当前 execution，不删除 Session。

所有可恢复失败都通过 `Result<T, CodingSdkError>` 返回。错误只包含 JSON-safe 的 code、message、phase 与 retryable 信息，不携带 provider error object、stack 或 cause。

:::note
`plan` 是稳定的 permission mode 名称，但当前里程碑尚未实现；创建时会返回 `coding_sdk.permission_mode_unsupported`。
:::
