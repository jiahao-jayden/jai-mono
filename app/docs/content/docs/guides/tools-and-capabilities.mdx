SDK 的内置工具名由 `CodingToolName` 定义：

`Read`、`Write`、`Edit`、`Glob`、`Grep`、`Bash`、`Skill`、`UpdateTodos`、`SpawnAgent`。

默认启用全部内置工具。`tools` 用于建立白名单，`excludeTools` 在最后移除工具；两个列表重叠时排除优先：

```ts
const created = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  cwd: process.cwd(),
  tools: ["Read", "Glob", "Grep", "Bash"],
  excludeTools: ["Bash"],
});
```

这会只保留 `Read`、`Glob` 和 `Grep`。非法工具名会让创建返回 `coding_sdk.invalid_tool_selection`。工具选择只影响 SDK 内置工具，不会删除 Extension 自己提供的工具。

## Extension 能力

通过 `defineExtension()` 提供工具、skills、hooks 和释放函数。工具名不能与内置工具或其他 extension 重名。

```ts
import { Type } from "@sinclair/typebox";
import { createCodingAgent, defineExtension } from "@jai/coding-agent";

const branchExtension = defineExtension({
  id: "current-branch",
  initialize: async () => ({
    tools: [
      {
        name: "CurrentBranch",
        description: "Return the branch selected by the host.",
        parameters: Type.Object({}),
        authorization: {
          owner: "core",
          permission: { sideEffect: "read", reason: "Reads host-provided branch metadata." },
        },
        execute: async () => ({
          content: [{ type: "text", text: "main" }],
        }),
      },
    ],
  }),
});

const created = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  extensions: [branchExtension],
});
```

每个 Extension 会以 `{ sessionId, cwd, permissionMode, configuration }` 初始化。`beforeToolCall` 可以继续、改写参数或 block；`afterToolCall` 观察成功与失败；`sessionStart` 处理初始化后的异步工作；`dispose()` 在创建失败或 `agent.close()` 时调用。

普通 Extension tool 使用 `authorization.owner: "core"`，所以仍由 SDK 的 permission mode、
rules 与 approval handler 管理。只有已实现完整授权事务的 Extension 才能声明
`authorization: { owner: "extension" }`；这会让 core 不再对同一次 tool call 额外审批。

Extension capability 不公开 `mcpServers`。Jai Agent Plugin 的发现与 MCP descriptor 适配属于 `@jai/extension` 和 Desktop/CLI 宿主；最终传给 SDK 的是普通 Extension tools、skills 和 hooks。
