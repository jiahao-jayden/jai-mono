---
title: 内置工具
description: 了解 Read、Bash、Edit 与 Write 四个内置工具的参数规格与裁剪配置。
---

SDK 内置了四个专为软件工程场景深度优化的基础工具。所有文件操作和命令执行均严格受工作目录 `cwd` 与权限引擎约束。

## 1. Read（文件读取）

读取工作区内的 UTF-8 文本文件。支持按行号截取大文件，避免无节制占用模型上下文：

```ts
// 工具输入参数
interface ReadParams {
  path: string;       // 相对 cwd 的文件路径，或合法绝对路径
  offset?: number;    // 起始行号（从 1 开始）
  limit?: number;     // 最大读取行数
}
```

- **带行号输出**：返回内容前会自动附加行号前缀（如 `1|const a = 1;`），帮助模型在随后的修改步骤中精确定位。
- **超长行保护**：单行字符数过长时自动截断并标记提示，防止异常压缩包或 minified JS 撑爆上下文。
- **并发友好**：`Read` 被标记为只读工具，在多文件排查场景下支持与其他只读操作并行调用。

## 2. Bash（命令执行）

在当前工作区沙箱中执行 POSIX Shell 命令：

```ts
interface BashParams {
  command: string;          // 要执行的 Shell 语句
  timeoutMs?: number;       // 超时时间（毫秒，默认 120,000）
  runInBackground?: boolean;// 是否作为后台任务异步运行
}
```

- **错误感知**：命令退出码（Exit Code）非零时将抛出结构化工具错误，模型能直接读取到 `stderr` 报错并自我纠正。
- **后台执行支持**：对于 `npm run dev` 或持久监听服务，设置 `runInBackground: true` 可立即返回并在后台挂载执行。详见 [后台任务指南](/docs/guides/background-agents)。

## 3. Edit（局部精确替换）

对已有文件进行精确、非重叠的多段文本替换：

```ts
interface EditParams {
  path: string;
  edits: Array<{
    oldText: string;  // 期望替换的原代码段（需唯一匹配）
    newText: string;  // 替换后的新代码段
  }>;
}
```

- **确定性保护**：`oldText` 在目标文件中必须唯一匹配。如果文件中存在多个相同片段导致歧义，工具会拒绝修改并要求模型扩大上下文范围，杜绝误改。
- **文件体积保护**：单次编辑支持最大 10MB 的常规源文件。

## 4. Write（文件创建与覆盖）

创建新文件或完全重写整个文件：

```ts
interface WriteParams {
  path: string;
  content: string; // 完整文件内容
}
```

- **自动建目录**：目标路径的上级父目录若不存在，工具会自动递归创建。
- **产物感知**：若写入的文件为 Markdown、HTML 或技术文档，SDK 会自动将其登记入当前会话的 `artifacts` 产物清单中。

## 裁剪内置工具集

默认情况下，四个工具全部启用。如果构建的是一个“只读审计 Agent”或“不能执行任意 Shell 的审查助手”，可以通过白名单或黑名单灵活裁剪：

```ts
const agent = await createCodingAgent({
  model: "anthropic/claude-3-7-sonnet",
  
  // 方式 1：白名单模式，仅开放只读工具
  tools: ["Read"],

  // 方式 2：黑名单模式，禁用 Bash 命令执行
  // excludeTools: ["Bash"],
});
```

如果需要额外增加如符号搜索（`find` / `grep`）、浏览器访问或外部 API 调用等高阶工具，请参阅 [扩展机制](/docs/concepts/extensions)。
