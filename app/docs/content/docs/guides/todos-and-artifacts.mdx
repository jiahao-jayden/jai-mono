title: Todos 与 Artifacts
description: 从公开状态读取 Agent 维护的 Todo 列表和 Markdown/HTML artifact 目录。
---

Todo 由可选的 `@jai/extension/todo` 提供。安装后，`UpdateTodos` 每次替换完整列表。公开项包含：

```ts
type TodoItem = {
  id: string;
  content: string;
  status: "pending" | "in_progress" | "completed" | "cancelled";
};
```

```ts
import { createCodingAgent } from "@jai/coding-agent";
import { createTodoExtension, todosFromExtensionState } from "@jai/extension/todo";

const result = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  extensions: [createTodoExtension()],
});
if (result.isOk()) {
  const agent = result.value;
  await agent.prompt("Plan the work");
  const todos = todosFromExtensionState(agent.state.extensions);
  console.log(todos?.items);
  await agent.close();
}
```

`state.extensions` 是只读 JSON 快照。Todo 通过现有 Extension sessionState 写入 journal；无状态时读取返回 `undefined`，主动清空后返回 `items: []`。不再读取旧顶层 `appState.todos`。

## Artifacts

成功的 `Write` 或 `Edit` 在目标文件为 Markdown 或 HTML 时会登记 artifact。公开项包含 `id`、`toolCallId`、`path`、`format` 与 `updatedAt`：

```ts
for (const artifact of agent.state.artifacts) {
  console.log(artifact.format, artifact.path);
}
```

Artifact ID 是 `artifact:<path>`；同一路径的更新会替换目录项，列表按更新时间由新到旧排列，并可持久化到 durable session 的 app state。

`codingArtifactsFromAppState(appState)` 是从已持久化 JSON app state 恢复并排序 artifact catalog 的公开 helper：

```ts
import { codingArtifactsFromAppState, type JsonObject } from "@jai/coding-agent";

function restoreArtifacts(appState: JsonObject) {
  return codingArtifactsFromAppState(appState);
}
```

:::note
Artifact 是目录元数据，不包含文件内容，也不证明文件仍存在。读取、打开或展示文件仍须经过宿主的路径和权限决策。
:::
