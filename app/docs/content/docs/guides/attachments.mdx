---
title: 附件
description: 向单次 prompt 提交本地文件或图片附件，理解 run-scoped 生命周期。
---

在对话中，用户经常需要上传本地截图、报错日志或参考规范。SDK 支持通过 `prompt()` 的第二个参数携带附件数据。

## 发送带有附件的 Prompt

```ts
import { createCodingAgent, type CodingAttachment } from "@jai/coding-agent";

// 构造附件元数据
const imageAttachment: CodingAttachment = {
  id: "att-screenshot-1",
  filename: "error-stack.png",
  mimeType: "image/png",
  size: 32_400,
  sourcePath: "/Users/username/Desktop/error-stack.png",
  // 图片附件通过懒加载异步函数返回 Base64 编码数据
  image: async () => ({
    type: "image",
    image: "iVBORw0KGgoAAAANSUhEUg...", // base64 数据
    mimeType: "image/png",
  }),
};

// 发起带有附件的任务
const result = await agent.prompt("分析截图中的前端布局错误，并修改对应页面代码", {
  attachments: [imageAttachment],
});
```

## 附件的作用域与生命周期

- **单轮运行有效（Run-Scoped）**：附件内容仅在当前发起的这一次 `prompt` 中被组装进上下文。后续轮次中模型能记住之前提取的关键结论，但附件原始数据不会被反复冗余发送，避免浪费多模态 Token。
- **动态路径可见性**：普通文本文件类附件提供有效的 `sourcePath` 之后，模型在上下文里会感知到该文件的物理绝对路径，并可按需调用内置的 `Read` 工具读取全文。
- **干预控制隔离**：`steer()` 与 `followUp()` 不接收附件，只接受纯文本干预指令。如需追加新的参考图片或文件，请发起新的 `prompt()` 调用。

:::warning
附件中可能包含开发者本地敏感路径或包含私有界面的截图。跨进程传输至前端 UI 时，应只传输 `filename`、`size` 与必要的缩略预览，避免直接在事件总线中广播全量原始数据。
:::
