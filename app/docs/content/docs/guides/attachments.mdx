---
title: 附件
description: 向一次 prompt 提交本地文件或图片，并理解附件的 run-scoped 生命周期。
---

附件只在一次 `prompt()` 运行内有效。调用方负责准备文件元数据，并在图片附件上提供可选的 `image()` 投影：

```ts
const screenshot = {
  id: "shot-1",
  filename: "error.png",
  mimeType: "image/png",
  size: 42_000,
  sourcePath: "/absolute/path/to/error.png",
  image: async () => ({
    type: "image" as const,
    image: "base64-encoded-image",
    mimeType: "image/png",
  }),
};

const result = await agent.prompt("分析这张截图中的错误信息，并给出排查步骤。", {
  attachments: [screenshot],
});
```

`id` 在本次 run 内必须唯一。`sourcePath` 是宿主已经验证过的实际本地文件路径；`image()` 返回模型可消费的 base64 image content。SDK 只在这次 prompt 中建立附件引用，运行结束后不要缓存或在下一次 prompt 复用这些引用。

附件不由 `steer()` 或 `followUp()` 消费；它们只接收文字。要发送另一份文件，使用新的 `prompt(text, { attachments })`。

:::warning
附件元数据和文件路径可能包含敏感信息。跨进程或展示到 UI 前，应单独投影 filename、大小和经过授权的预览信息；不要直接把内部路径或 base64 内容作为通用事件数据传递。
:::
