让自主 Agent 在本地项目中执行写文件或 Shell 脚本时，安全隔离至关重要。SDK 提供了多层防护体系：模式预设、静态 AST 语法扫描、工作区逃逸拦截与可扩展的人工审批回调。

## 四档权限模式

通过 `permissionMode` 选项指定全局授权基调：

```ts
export type CodingPermissionMode = "ask" | "allow" | "auto" | "plan";
```

| 模式 | 运行机制 | 适用场景 |
|---|---|---|
| `ask`（默认） | 工作区内的只读操作直接放行；写文件、未知命令、敏感命令一律暂停并触发 `requestApproval` | 绝大多数日常开发与人机协同交互 |
| `allow` | 工作区内的文件读写直接执行；但越界访问、破坏性命令与高危操作仍然会触发拦截与审批 | 开发者信任的特定自动化流水线 |
| `auto` | 遇到本需询问的操作时，先由宿主配置的后台审核器（如辅助模型或规则引擎）进行异步评估，未通过或超时才回退为人工审批 | 期望提升流畅度、减少确认打扰的高阶场景 |
| `plan` | 强只读模式：拒绝所有产生副作用的写文件与非只读命令，仅生成方案或分析报告 | 纯代码审查、架构诊断与只读梳理任务 |

## 静态规则配置（PermissionSettings）

如果需要为特定目录或命令配置持久化规则，可以在宿主层组装权限配置规则：

```ts
const settings = {
  defaultMode: "ask",
  permission: {
    // 允许读取工作区内所有文件
    "file.read": "allow",
    // 保护敏感目录，允许修改 src
    "file.write": {
      "**/*.env*": "deny",
      ".git/**": "deny",
      "src/**": "allow",
    },
    // 白名单允许常用只读工具命令，危险命令弹窗确认
    "process.exec": {
      "git status": "allow",
      "git diff": "allow",
      "npm test": "allow",
      "rm *": "ask",
    },
  },
};
```

### 路径与命令匹配规则

- 路径规则基于 glob 规范。以 `/` 开头或相对路径均按工作区根目录解析；`~` 开头按用户家目录解析。
- `*` 匹配单个目录层级内的内容；`**` 跨越任意目录层级。
- 命令行规则以空格结尾（如 `"git *"`）时表示前缀匹配，涵盖其所有子命令与参数组合。

## 敏感与破坏性命令拦截

对于 `Bash` 工具发起的命令，SDK 在求值前会经过内置防御层：

1. **AST 结构化分析**：基于 Tree-sitter 对输入的 Shell 命令进行抽象语法树解析，拆解管道、复合语句（`;`、`&&`、`||`）与命令包装器（如 `nohup`、`sudo`、`timeout`），获取底层真实执行的可执行文件。
2. **熔断保护（Circuit Breaker）**：诸如针对根目录或家目录的无差别删除命令（如 `rm -rf /` 或 `rm -rf ~`），即使在 `allow` 模式下也会被底层硬性熔断阻断，不会直接放行。
3. **敏感信息脱敏**：审批请求中的命令如果携带形如 `TOKEN=xxx`、`--password yyy` 的参数，在传递给审批 UI 时会被自动替换为 `[redacted]`，防止密钥泄漏。

## 审批回调接口（`requestApproval`）

当操作需要人工介入时，SDK 调用宿主传入的异步回调函数：

```ts
export type CodingPermissionDecision = "deny" | "allowOnce" | "alwaysAllow";

const agent = await createCodingAgent({
  model: "anthropic/claude-3-7-sonnet",
  permissionMode: "ask",
  requestApproval: async (request, signal) => {
    const { summary, canAlwaysAllow } = request;
    
    // 渲染审批内容给用户
    console.log(`[待审批操作] ${summary.title}`);
    if (summary.command) console.log(`命令: $ ${summary.command}`);
    if (summary.path) console.log(`目标路径: ${summary.path}`);
    console.log(`风险等级: ${summary.risk}`); // "low" | "medium" | "high"

    // 返回决策
    // "deny": 拒绝执行
    // "allowOnce": 仅本次放行
    // "alwaysAllow": 本次放行并在此会话中记住该规则
    return "allowOnce";
  },
});
```
