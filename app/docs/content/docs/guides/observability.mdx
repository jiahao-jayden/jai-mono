在生产级应用中，我们需要洞察 Agent 执行过程中的耗时分布、Token 消耗以及每一次工具调用的上下文。SDK 内置了轻量级、无外部强依赖的可观测性接口。

## 遥测观察器（CodingAgentTelemetryObserver）

`CodingAgentTelemetryObserver` 实现了 SDK 内置的遥测旁路接口：

```ts
import { CodingAgentTelemetryObserver, createCodingAgent } from "@jai/coding-agent";

// 初始化遥测观察器
const observer = new CodingAgentTelemetryObserver({
  telemetry: customTelemetryContext, // 宿主实现的 Telemetry 上下文
  operationId: "op-123456",
  sessionId: "session-abc",
});

// 在创建 Agent 时注入旁路监听
const agent = (await createCodingAgent({
  model: "anthropic/claude-3-7-sonnet",
  cwd: process.cwd(),
  permissionTelemetryObserver: observer,   // 记录权限评估与审批流转
  modelRequestTelemetryObserver: observer, // 记录模型请求上下文与实际发出参数
})).value;

// 还可以显式消费普通生命周期事件
agent.subscribe((event) => {
  observer.observeAgentEvent(event);
});
```

所有 `observe*` 方法在内部均包裹了安全的错误隔离机制，任何遥测异常都不会干扰 Agent 核心业务流程的推进。

## 标准 Span 追踪树

观察器按照层次化的调用树组装执行追踪数据：

```text
jai.run                           # 单次完整任务根执行
└── jai.turn                      # 单一交互轮次（模型请求 + 工具执行）
    ├── jai.model_attempt         # 向模型服务端发起连接
    │   └── jai.model_stream      # 消费流式响应并组装内容
    ├── jai.tool_call             # 具体的工具调用生命周期与耗时
    └── jai.permission            # 权限判定分析
        └── jai.approval          # 人工审批等待耗时
```

## 隐私与脱敏原则

为了保证日志在经过集中采集与上报时不泄漏用户源码与机密凭据，SDK 的遥测层强制执行脱敏：

- 追踪 Span 的元数据中仅包含确定性的标识符（如 `sessionId`、`toolName`、`toolCallId`、`contentIndex`）。
- 具体的模型输入文本、文件内容、Shell 执行参数以及输出结果不会无序扩散到通用遥测 Sink 中。
- 敏感指令（如 `TOKEN=...` 或包含密码的参数）会在权限判定阶段通过内置脱敏器预先过滤。
