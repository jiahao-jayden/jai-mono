> **旧文档勘误**：旧版 `observability.mdx` 讲的是 Desktop 的 UI 面板，
> 不是 SDK。SDK 侧的可观测性是下面这个 observer。

## CodingAgentTelemetryObserver

```ts
import { CodingAgentTelemetryObserver } from "@jai/coding-agent";

const observer = new CodingAgentTelemetryObserver({
  telemetry,      // TelemetryContext（@jai/telemetry 契约）
  operationId,    // 本次 Operation 标识
  sessionId,      // 会话标识
  // now?: () => number  // 测试可注入单调时钟；生产缺省 Date.now
});
```

它同时实现 `ModelRequestObserver` 与 `PermissionTelemetryObserver`，
可直接挂到 `createCodingAgent` 的两个旁路选项上：

```ts
await createCodingAgent({
  model: "anthropic/claude-sonnet-4-5",
  permissionTelemetryObserver: observer,  // 只观察权限事实，不参与判定
  modelRequestTelemetryObserver: observer, // provider 请求发出前观察最终上下文
});
```

另外三个手动调用的观测点：

```ts
observer.observeAgentEvent(event);   // CodingAgentEvent
observer.observeEffectEvent({ type: "model_reserved" | "tool_reserved", ... }); // 稳定 identity，不带参数/结果/内容
observer.observeModelRequest(observation);
observer.observePermissionEvent(event);
observer.close(); // 标记 aborted，结算未完成 span
```

## span 层级

`startSpan` 的 name 构成的树：

```text
jai.run
└── jai.turn
    ├── jai.model_attempt
    │   └── jai.model_stream
    ├── jai.tool_call
    └── jai.permission
        └── jai.approval
```

固定词汇表：7 个 `jai.*` span 名、17 个事件名（`@jai/telemetry` 的
`vocabulary.ts`）。投影函数强制"原文内容绝不进入通用 sink"——span 只带
稳定 identity（如 `assistantEntryId`、`toolCallId`、`toolName`），不带参数、
结果或消息内容。

## 用户遥测策略

```ts
import { defaultUserTelemetryPolicy } from "@jai/coding-agent";
// UserTelemetryPolicy：控制内容捕获开关等
```

`observer.enabled` 的判定：`!closed && (run?.contentCaptureEnabled ??
telemetry.contentCaptureEnabled)`。所有 `observe*` 方法内部 try/catch，
观测异常会被吞掉，不影响 agent 运行。

> `@jai/telemetry` 包本身是 private 的内部契约层（`TelemetryContext` /
> `TelemetrySpan` / `TelemetrySink` 端口 + `NoopTelemetryContext` /
> `InMemoryTelemetryContext` + `./node` 的 JSONL 文件 sink），不是 SDK 公开
> API——Host 实现 `TelemetryContext` 端口即可对接。
