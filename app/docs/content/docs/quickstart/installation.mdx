# 安装

## 前置条件

- **Node.js 20 或更新版本**（`packages/coding-agent` 的 engines 字段要求 `>=20`）。
- [Bun](https://bun.sh/)（仓库的包管理与测试用 Bun）。
- 一个可用的模型 provider：Anthropic、OpenAI，或任何兼容 OpenAI API 的服务
  （本地 Ollama / LM Studio、自托管网关均可），以及对应的 API key。

## 在 monorepo 内使用

`@jai/coding-agent` 尚未发布到 npm。目前在仓库内开发，直接 clone 后安装依赖：

```bash
git clone https://github.com/jiahao-jayden/jai-mono.git
cd jai-mono
bun install
```

workspace 内的包通过 workspace 协议互相引用，`@jai/coding-agent` 开箱即用。
npm 发布后，这里会更新为 `npm install @jai/coding-agent`。

## 验证安装

```ts
import { createCodingAgent, resolveSdkModel } from "@jai/coding-agent";

// 只解析 model 字符串，不发起网络请求
const resolved = resolveSdkModel("anthropic/claude-sonnet-4-5", {
  apiKey: process.env.ANTHROPIC_API_KEY,
});
console.log(resolved.model.id, resolved.provider.id);
```

model 字符串格式为 `"<provider>/<model>"`（按**第一个** `/` 分隔，
modelId 本身可以含 `/`）。provider 前缀只允许三者：

| 前缀 | 实际 API 协议 |
|---|---|
| `anthropic` | Anthropic Messages API |
| `openai` | OpenAI Responses API |
| `openai-compatible` | OpenAI Chat Completions 兼容协议 |

`provider.apiKey` 缺省读取环境变量 `ANTHROPIC_API_KEY` / `OPENAI_API_KEY`，
`baseUrl` 缺省读取 `ANTHROPIC_BASE_URL` / `OPENAI_BASE_URL`。
格式不对（缺少 `/`、以 `/` 开头或结尾）会得到
`coding_sdk.invalid_model_ref`；前缀不在三者之内会得到
`coding_sdk.unsupported_provider`。详见 [API：createCodingAgent](/docs/api-reference/create-coding-agent)
和 [API：错误](/docs/api-reference/errors)。
