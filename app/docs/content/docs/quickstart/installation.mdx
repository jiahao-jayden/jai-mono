---
title: 安装

---

## 前置条件

- Node.js 20 或更新版本。
- 一个空目录或现有 TypeScript 项目。
- OpenAI API key，以及该账户可访问的模型 ID。

<Steps>
  <Step title="初始化项目">

```bash
mkdir jai-agent-quickstart
cd jai-agent-quickstart
npm init -y
npm pkg set type=module
```
  </Step>
  <Step title="安装 packages">

```bash
npm install @jai/coding-agent @jai/ai
npm install --save-dev typescript tsx @types/node
```

    也可以使用 `pnpm add`、`bun add` 或 `yarn add` 安装相同 packages。
  </Step>
  <Step title="配置 TypeScript">
    新建 `tsconfig.json`：

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```
  </Step>
  <Step title="设置模型凭据">

```bash
export OPENAI_API_KEY="sk-..."
export OPENAI_MODEL="gpt-4.1-mini"
```

    `OPENAI_MODEL` 可省略；Quickstart 当前以 `gpt-4.1-mini` 为示例默认值。模型供应会变化，请替换为你的 OpenAI 账户实际可用的模型，并同步核对示例中的 context window 与最大输出 token 元数据。
  </Step>
</Steps>

应用代码从正式入口导入：

```ts
import { createCodingAgent, type CodingAgentHost } from "@jai/coding-agent";
import { OpenAIProvider, type Model } from "@jai/ai";
```

继续：[创建第一个 Agent](/docs/quickstart/create-your-first-agent)。
