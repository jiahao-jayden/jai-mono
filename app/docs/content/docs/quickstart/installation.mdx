## 环境要求

- **Node.js**：20.0.0 或更高版本。
- **包管理器**：推荐使用 [Bun](https://bun.sh/)（与 monorepo 开发环境保持一致），亦支持 pnpm 或 npm。
- **模型服务**：已激活的 Anthropic、OpenAI 或任意兼容 OpenAI Chat Completions 协议的第三方/本地服务端点（如 Ollama、vLLM、LM Studio），并准备好相应的 API Key。

## 获取 SDK

在当前 monorepo 环境中，各应用通过 workspace 协议直接引用：

```bash
git clone https://github.com/jiahao-jayden/jai-mono.git
cd jai-mono
bun install
```

在你的 Node.js 或 TypeScript 项目中，安装 SDK 包：

```bash
npm install @jai/coding-agent
# 或
bun add @jai/coding-agent
```

## 配置模型凭据

SDK 默认从标准环境变量中读取访问密钥和服务端地址：

| 模型厂商 | 密钥环境变量 | 地址环境变量（可选） |
|---|---|---|
| Anthropic | `ANTHROPIC_API_KEY` | `ANTHROPIC_BASE_URL` |
| OpenAI | `OPENAI_API_KEY` | `OPENAI_BASE_URL` |
| OpenAI-Compatible | 显式传入 `apiKey` | 显式传入 `baseUrl` |

在终端中导出环境变量：

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
# 或者
export OPENAI_API_KEY="sk-..."
```

## 验证模型标识

SDK 提供静态解析辅助函数 `resolveSdkModel`，可在不发起真实网络调用的前提下校验模型字符串与提供商配置：

```ts
import { resolveSdkModel } from "@jai/coding-agent";

// 模型标识格式为 "<provider>/<modelId>"
const resolved = resolveSdkModel("anthropic/claude-3-7-sonnet", {
  apiKey: process.env.ANTHROPIC_API_KEY,
});

console.log("Provider:", resolved.provider.id); // "anthropic"
console.log("Model:", resolved.model.id);       // "claude-3-7-sonnet"
```

前缀限定为 `anthropic`、`openai` 或 `openai-compatible`。若格式错误或前缀不受支持，函数将抛出明确的输入校验异常。

准备就绪后，继续阅读：[创建第一个 Agent](/docs/quickstart/create-your-first-agent)。
