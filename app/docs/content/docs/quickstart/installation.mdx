title: 安装

---

## 前置条件

- Node.js 20 或更新版本。
- 一个 TypeScript 项目。
- OpenAI 或 Anthropic 的 API key，以及账户可访问的模型 ID。

<Steps>
  <Step title="初始化项目">

```bash
mkdir jai-agent-quickstart
cd jai-agent-quickstart
npm init -y
npm pkg set type=module
```
  </Step>
  <Step title="安装 SDK">

```bash
npm install @jai/coding-agent
npm install --save-dev typescript tsx @types/node
```

    也可以使用 `pnpm add`、`bun add` 或 `yarn add`。
  </Step>
  <Step title="配置 TypeScript">

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "skipLibCheck": true
  }
}
```
  </Step>
  <Step title="设置模型凭据">

```bash
export OPENAI_API_KEY="sk-..."
```

    使用 Anthropic 时改为 `ANTHROPIC_API_KEY`。模型 ID 在创建 Agent 时直接写入 `model`，例如 `openai/gpt-4.1-mini` 或 `anthropic/claude-sonnet-4-20250514`。
  </Step>
</Steps>

应用只需要从正式 root 入口导入：

```ts
import { createCodingAgent, type CodingAgentCreateOptions } from "@jai/coding-agent";
```

不要安装或导入 `@jai/ai` 来构造模型对象，也不要 deep import SDK 内部模块。继续：[创建第一个 Agent](/docs/quickstart/create-your-first-agent)。
