---
title: 创建你的第一个 Agent
description: 用 createCodingAgent 创建 agent，发送 prompt，订阅事件，读取结果并关闭。
---

下面 30 行代码走通 SDK 的完整链路：创建 → 订阅事件 → prompt → 结果 → 关闭。

```ts
import { createCodingAgent } from "@jai/coding-agent";

const created = await createCodingAgent({
  model: "anthropic/claude-sonnet-4-5",
  provider: { apiKey: process.env.ANTHROPIC_API_KEY },
  cwd: "/path/to/your/project",
  // session 缺省为 { kind: "ephemeral" }：临时会话，用完即焚
});

if (created.isErr()) {
  console.error(created.error.code, created.error.message);
  process.exit(1);
}
const agent = created.value;

// 订阅事件：流式文本、工具调用都会以回调推送
const unsubscribe = agent.subscribe((event) => {
  if (event.type === "message_update" && event.assistantEvent.type === "text_delta") {
    process.stdout.write(event.assistantEvent.delta);
  }
  if (event.type === "tool_execution_start") {
    console.log(`\n[tool] ${event.toolName}`);
  }
});

const result = await agent.prompt("列出这个目录下的文件，并告诉我这是什么项目");

if (result.isOk()) {
  const last = result.value.messages.at(-1);
  console.log("\n--- done ---", last?.role);
}

unsubscribe();
await agent.close();
```

## 要点

1. **`createCodingAgent` 是 async 的**，返回
   `Promise<Result<CodingAgent, CodingSdkError>>`（`better-result`）。
   用 `result.isOk()` / `result.isErr()` 判断，成功时取 `result.value`。
   创建失败（如 model 字符串非法、扩展激活失败）的 phase 是 `runtime_creation`。
2. **`model` 是唯一必填字段**，格式 `"provider/model"`。
   `provider.apiKey` 缺省会读 `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` 环境变量，
   所以本地开发时常常连 `provider` 都可以省略。
3. **`prompt` 发送一轮新提示并运行到结束**，返回整轮的
   `CodingRunResult { sessionId, messages, state }`。空字符串会直接返回
   `coding_sdk.empty_prompt` 错误（phase `admission`）。
4. **事件是回调式推送**：`subscribe(listener)` 返回取消订阅函数。
   没有 RxJS / AsyncIterator 风格的流。`agent.state` 是一个 getter，
   每次读取都实时投影当前状态。
5. **`close()` 必须调用**：它会 abort 运行中的任务、等待落盘、逆序 dispose
   扩展，并删除 ephemeral 会话的临时目录。重复 close 是安全的（返回 ok）。
