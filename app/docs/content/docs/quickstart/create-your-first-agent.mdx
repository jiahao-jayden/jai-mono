---
title: 创建第一个 Agent
description: 创建一个 ephemeral、只读的 Agent，读取当前目录并正确处理 Result 与资源关闭。
---

在项目根目录新建 `agent.ts`。下面的文件只依赖 `@jai/coding-agent`；默认从 `OPENAI_API_KEY` 读取凭据。

```ts
// @docs-compile
import { createCodingAgent } from "@jai/coding-agent";

const created = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  cwd: ".",
  session: { kind: "ephemeral" },
  permissionMode: "plan",
  instructions: "只读取和分析文件，不修改项目。",
});

if (created.isErr()) {
  console.error(`[${created.error.phase}] ${created.error.code}: ${created.error.message}`);
} else {
  const agent = created.value;
  try {
    const run = await agent.prompt("读取当前项目的 README，用中文总结项目用途和主要使用方法。");
    if (run.isErr()) {
      console.error(`[${run.error.phase}] ${run.error.code}: ${run.error.message}`);
    } else {
      const text = run.value.messages
        .filter((message) => message.role === "assistant")
        .flatMap((message) => message.content)
        .filter((part) => part.type === "text")
        .map((part) => part.text)
        .join("\n");
      console.log(text);
    }
  } finally {
    const closed = await agent.close();
    if (closed.isErr()) console.error(closed.error);
  }
}
```

运行：

```bash
npx tsx agent.ts
```

`plan` 固定拒绝 `Write`、`Edit` 和可写 Bash 操作，适合分析、审查与方案生成。首次运行会请求模型并产生相应费用。把模型改为你的账户可访问的模型 ID；SDK 不要求你手工维护模型 metadata。

`createCodingAgent()`、`prompt()` 和 `close()` 的可恢复失败都通过 `Result` 返回。缺少 API key、模型不可用或 session 无效时，先检查 `error.code` 与 `error.phase`；`finally` 中始终尝试关闭 Agent。
