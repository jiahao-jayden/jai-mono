---
title: 创建配置
description: 了解 createCodingAgent 的基础配置、提供商选项与宿主控制参数。
---

`createCodingAgent` 函数接收一个清晰的配置对象。宿主负责解析自身的用户设置与环境参数，并将本次执行所需的配置注入 SDK。

## 基础配置示例

```ts
import { createCodingAgent } from "@jai/coding-agent";

const created = await createCodingAgent({
  model: "openai/gpt-4o",
  cwd: process.cwd(),
  permissionMode: "plan",
  session: { kind: "ephemeral" },
});
```

- `model`：必填。格式为 `<provider>/<modelId>`，支持 `anthropic`、`openai` 与 `openai-compatible`。
- `cwd`：工作目录路径。内置工具的所有相对路径操作与命令执行均以该目录为基准。缺省值为 `process.cwd()`。
- `session`：会话模式。缺省为临时内存会话 `{ kind: "ephemeral" }`。

## 自定义 Provider 选项

当使用代理网关、自建兼容服务或需要独立注入 API 凭据时，可以使用 `provider` 字段：

```ts
const created = await createCodingAgent({
  model: "openai-compatible/deepseek-coder",
  provider: {
    baseUrl: "https://api.your-gateway.com/v1",
    apiKey: "sk-your-key",
    headers: {
      "X-Custom-Tenant": "prod-01",
    },
    // 可选：流式响应无数据到达的空闲超时时间（毫秒），默认 300000（5分钟）
    idleTimeoutMs: 120_000,
  },
});
```

- `anthropic` 协议使用 `x-api-key` 请求头鉴权。
- `openai` 及 `openai-compatible` 协议支持 Bearer Token 或免鉴权模式（`authentication: "none"`）。
- `baseUrl` 必须为合法的 HTTPS 地址，或本地回环 HTTP 地址（如 `http://127.0.0.1:11434`）。

## 行为与上下文控制

除了基础参数外，宿主还可以通过以下选项精细调整 Agent 的行为逻辑：

- **系统指令注入**：`instructions` 字段的内容将作为额外系统指令追加到提示词尾部，用于约定代码风格或项目背景。
- **轮次限制**：`maxTurns` 设定单次任务允许的最大往返交互轮次，防止 Agent 在死循环或复杂试错中耗尽预算。
- **工具裁剪**：通过 `tools`（白名单）或 `excludeTools`（黑名单）限制内置工具的可用范围。
- **上下文压缩策略**：`autoCompaction` 控制是否在会话 Token 达到上限前自动触发压缩，`compactionSummaryInstructions` 可定制压缩摘要的内容偏好。

完整选项清单请参考 [API 参考：createCodingAgent](/docs/api-reference/create-coding-agent)。
