---
title: 上下文压缩
description: 了解自动与手动会话压缩机制，在超长任务中保持上下文连贯与成本可控。
---

在涉及多轮对话与大量代码读写的长任务中，消息历史会快速膨胀并触及模型的上下文窗口上限（Context Window）。SDK 内置了智能切点推导与摘要替换机制，确保会话持续推进。

## 自动压缩（Auto Compaction）

创建 Agent 实例时，`autoCompaction` 选项默认开启：

```ts
const agent = await createCodingAgent({
  model: "anthropic/claude-3-7-sonnet",
  autoCompaction: true, // 默认开启
  // 可选：指定模型生成摘要时的引导提示
  compactionSummaryInstructions: "重点保留修改过的文件清单、未完成的 TODO 以及关键测试错误日志",
});
```

### 触发条件

自动压缩通常在两种情况下发生（体现在 `compaction_start` 的 `trigger` 字段中）：

1. **`threshold`（阈值触发）**：当前会话上下文估算 Token 数达到预警安全线（通常为窗口上限的 85%~90%），在发起新请求前自动执行修剪。
2. **`overflow`（溢出兜底）**：模型服务端明确返回窗口溢出（`contextOverflow`）错误时，SDK 自动回退、执行紧急压缩并透明重试。

### 压缩算法要点

- **保留最新轮次**：压缩时会自动保留末尾若干轮最近对话的完整细节，防止用户刚发送的指导信息被截断。
- **成对保留保护**：算法会自动探测工具调用（ToolCall）与工具执行结果（ToolResult）的配对边界，绝不会切断单次调用的中间状态，避免下游模型因协议碎片报错。
- **历史摘要替换**：被裁剪掉的较早历史记录会被单向投影为一条紧凑的系统/用户摘要消息，承载核心上下文继续流转。

## 手动压缩（Manual Compaction）

宿主可在业务逻辑决定的适当时机（例如一个大功能模块重构完成并测试通过后）主动触发压缩：

```ts
// 当 agent 处于 idle 状态时调用
const result = await agent.compact();

if (result.isOk()) {
  console.log("手动压缩完成，会话已精简");
} else {
  console.error("压缩失败:", result.error.message);
}
```

也可以为耗时的摘要生成过程传入 `AbortSignal` 进行超时或取消控制：

```ts
const controller = new AbortController();
setTimeout(() => controller.abort(), 15_000);

await agent.compact(controller.signal);
```

## 事件观测

压缩过程是完全可观测的。通过订阅事件可以获知压缩的始末：

```ts
agent.subscribe((event) => {
  if (event.type === "compaction_start") {
    console.log(`[压缩中] 触发来源: ${event.trigger}, 压缩前 Token: ${event.tokensBefore}`);
  } else if (event.type === "compaction_end") {
    console.log("[压缩完成] 会话历史已更新");
  }
});
```
