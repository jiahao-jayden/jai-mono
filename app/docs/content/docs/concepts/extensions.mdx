title: 扩展
description: 使用 defineExtension 声明自定义工具、生命周期 Hooks 与动态工具目录。
---

扩展（Extension）是向 Agent 注入专有能力的核心机制。SDK 采用纯声明式的扩展契约：扩展是一个包含元数据、工具列表、钩子与生命周期函数的纯 JavaScript 对象，通过 `defineExtension` 进行强类型定义。

## 声明一个扩展

```ts
import { defineExtension, createCodingAgent } from "@jai/coding-agent";

// 使用 defineExtension 保留字面量类型推导
const gitExtension = defineExtension({
  id: "git-tools",
  tools: [
    {
      name: "git_status",
      description: "检查当前工作区的 git 状态与修改文件列表",
      parameters: {
        type: "object",
        properties: {
          short: { type: "boolean", description: "是否使用简短格式输出" },
        },
      },
      execute: async (args, context) => {
        // 执行逻辑
        return {
          content: [{ type: "text", text: "## main...origin/main\n M src/index.ts" }],
        };
      },
    },
  ],
  hooks: {
    beforeAgentStart: async (runtime, input) => {
      console.log("任务开始前的拦截准备");
    },
  },
});

// 装配到 Agent 实例
const agent = await createCodingAgent({
  model: "anthropic/claude-3-7-sonnet",
  extensions: [gitExtension],
});
```

## 生命周期与 Hooks

扩展可以挂载到 Agent 运行的各个关键阶段，实现守卫、前置注入或后置指标上报：

| Hook 阶段 | 触发时机与用途 |
|---|---|
| `beforeAgentStart` | 任务提交（`prompt`）后立即触发；在此阶段可执行前置准入校验，或阻断本次执行 |
| `sessionStart` | 扩展随会话首次建立或恢复时触发一次 |
| `turnStart` / `turnEnd` | 每一个完整的模型推理或工具执行循环轮次的开始与落定 |
| `beforeModelCall` | 向大模型发送上下文前触发；可动态追加临时指导或修改参数 |
| `afterModelCall` | 捕获大模型原始响应后、开始派发工具调用前触发 |
| `beforeToolCall` | 任何工具（无论内置还是扩展工具）即将执行前触发 |
| `afterToolCall` | 工具执行完成后触发；可监听并记录文件变更与输出结果 |
| `agentSettled` | 整场会话进入最终稳定态时触发 |

### 实例生命周期

- `activate(context)`：Agent 初始化时同步或异步执行，返回该扩展私有的运行实例。若激活失败，Agent 初始化整体终止。
- `deactivate(runtime)`：在 `agent.close()` 时逆序触发，用于释放长连接、关闭子进程或持久化状态。

## 动态目录（Tool Catalogs）

当工具数量极大时，将所有工具 Schema 一次性塞入 Context 会严重浪费 Token 并降低指令遵循率。扩展支持声明式 Catalog，提供按需暴露机制：

```ts
const apiCatalogExtension = defineExtension({
  id: "corporate-apis",
  catalogs: [
    {
      id: "crm-apis",
      loading: "deferred", // 延迟发现
      description: "客户关系与订单管理系统的数百个业务 API",
      discover: async (query) => {
        // 按需拉取相关工具
        return matchedTools;
      },
    },
  ],
});
```

在 `loading: "deferred"` 模式下，模型初期只会感知到元工具，仅在模型主动发起搜索时，对应具体工具才会被检索并注入上下文。

## 官方扩展库（`@jai/extension`）

jai-mono 官方提供了一系列即插即用的扩展包：

- **`connector`**：标准化数据连接器。
- **`agent-plugins`**：兼容跨生态的标准 Agent 插件包与 Manifest 体系。
- **`jai.skills`**：为 Agent 赋予渐进式技能加载能力（Skill 机制）。
- **`jai.fff-search`**：提供工程级代码符号与文本检索工具（`find` 与 `grep`）。
- **`jai.web-search`**：外挂联网搜索与网页内容抓取能力。
- **`mcp`**：无缝对接 Model Context Protocol (MCP) 服务端。
- **`jai.todo`**：任务进度追踪与待办清单维护。
- **`jai.subagent`**：派生子 Agent 递归处理复杂子任务。
