---
title: State 与 Events
description: 读取不可变状态快照，订阅 streaming、工具执行与 compaction 事件，并处理 JSON-safe 数据边界。
---

`agent.state` 是当前快照，包含 `sessionId`、`status`、`messages`、`todos`、`artifacts`、`appState` 与可选 `error`。读取 `appState` 时 SDK 会 clone 数据，调用方不能通过引用修改内部状态。

`subscribe(listener)` 观察后续事件，并返回 unsubscribe：

```ts
const unsubscribe = agent.subscribe((event) => {
  if (event.type === "tool_execution_start") {
    console.log("工具开始", event.toolCallId, event.toolName, event.args);
  }
  if (event.type === "message_update" && event.assistantEvent.type === "text_delta") {
    process.stdout.write(event.assistantEvent.delta);
  }
});

try {
  const result = await agent.prompt("解释这个仓库的主要模块。");
  if (result.isErr()) console.error(result.error);
} finally {
  unsubscribe();
}
```

事件覆盖 Agent、turn、message、tool execution 与 compaction：

- `agent_start` / `agent_end`
- `turn_start` / `turn_end`
- `message_start` / `message_update` / `message_end`
- `tool_execution_start` / `tool_execution_update` / `tool_execution_end`
- `compaction_start` / `compaction_end`

公开消息、工具参数、工具结果、compaction outcome 与 state error 都是 JSON-safe 数据。JSON-safe 不代表内容可直接展示：跨进程或 UI 边界仍应按用途投影白名单 DTO，避免无意显示 prompt、路径、命令或模型输出中的敏感内容。

完整字段见 [State 与 Events API](/docs/api-reference/state-and-events)，可运行模式见 [观察事件](/docs/examples/observe-events)。
