title: Prompts 与控制
description: 掌握任务提交、运行中转向（steer）、后续排队（followUp）与任务取消。
---

Agent 的主循环运行支持细粒度的控制指令。宿主不仅可以提交新的任务，还可以在任务执行过程中动态调整方向或排队后续工作。

## 提交任务：`prompt`

`prompt()` 提交一轮新的任务提示词，驱动 Agent 运行至本次执行结束：

```ts
const run = await agent.prompt("分析当前项目的单元测试覆盖率，找出缺少测试的核心模块");

if (run.isOk()) {
  console.log("执行完成，最新状态:", run.value.state.status);
  console.log("产生消息数:", run.value.messages.length);
} else {
  console.error("执行出错:", run.error.code, run.error.message);
}
```

并发调用 `prompt()` 时，后续调用不会打断正在进行的工作，而是自动进入串行等待队列，在前一个任务结束后按序执行。

## 动态控制：`steer` 与 `followUp`

当 Agent 正在执行耗时较长的多步操作时，宿主可以通过 `steer` 或 `followUp` 介入流程：

```ts
// 1. 中途纠偏转向：打断当前正在思考或执行的子流程，优先处理新指令
await agent.steer("暂停当前测试，先修复刚才发现的那个类型错误");

// 2. 追加后续计划：将输入放入就绪队列，当前完整任务结束后立刻跟进
await agent.followUp("修复完成后，重新跑一遍全量测试确认没有回归");
```

### 两种干预方式的区别

| 控制方法 | 触发时机 | 典型场景 |
|---|---|---|
| `agent.steer(text)` | **立即插队**：中断后续工具调用的调度，插入当前轮次成为最高优先级指导 | 用户发现 Agent 走错方向，需要紧急刹车或重新明确目标 |
| `agent.followUp(text)` | **自然排队**：等待当前整轮任务完全落定后，自动发起下一轮调用 | 用户在 Agent 操作期间想到了补充需求，按顺序承接处理 |

## 生命周期与安全中断

- **`agent.abort()`**：主动向 Agent 发出取消信号。正在等待模型返回或工具执行的流程将停止推进。
- **`agent.waitForIdle()`**：返回一个 Promise，等待当前所有排队的任务与工具彻底结束并回归空闲状态（`idle`）。常用于用户关闭窗口或切换工作区前的安全等待。
- **`agent.generateTitle(firstMessage)`**：基于首条用户消息和初始响应，使用当前模型快速生成一段精准简短的会话标题（8 个词以内），便于在宿主 UI 的侧边栏展示。
- **`agent.close()`**：终止内部任务、完成日志刷盘、调用各扩展的 `deactivate` 钩子并清理临时沙箱目录。重复调用 `close()` 是幂等且安全的。
