---
title: Prompts 与控制
description: 使用 prompt、steer、followUp、abort、waitForIdle 和 generateTitle 控制一个运行中的 Agent。
---

`prompt()` 提交一次完整运行；返回的 `Result` 包含本次运行的消息和结束后的状态。多个 prompt 会按照调用顺序串行执行。

```ts
const run = await agent.prompt("检查当前目录的测试失败原因，并给出修复计划。");
if (run.isErr()) {
  console.error(run.error);
} else {
  console.log(run.value.state.status);
}
```

在运行期间，`steer()` 发送一条优先处理的文字指令，`followUp()` 则把文字加入后续队列：

```ts
const steered = await agent.steer("先停止修改，只总结已经发现的问题。");
const queued = await agent.followUp("接着列出三个最小修复方案。");
```

两者都只接受非空字符串，并返回 `Result<void, CodingSdkError>`。附件只由 `prompt(text, { attachments })` 消费；不要向 `steer()` 或 `followUp()` 传对象。

## 生命周期控制

- `abort()`：请求取消当前运行；仍应等待调用的 Result，并根据事件更新 UI。
- `waitForIdle()`：等待已接纳的工作结束，适合在切换视图或关闭前同步状态。
- `generateTitle(firstMessage)`：基于首条用户消息生成短标题，返回 `Result<string, CodingSdkError>`。
- `close()`：取消当前工作、等待队列收尾并释放资源。关闭后不再提交 prompt 或控制指令。

不要用 `state.status === "running"` 自己实现队列控制。状态是显示快照；调用方法与它们的 `Result` 才是并发和生命周期边界。
