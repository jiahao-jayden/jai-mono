---
title: 示例：恢复已有会话
description: 按 sessionId 回放历史 Journal，恢复 Agent 状态机并继续后续任务。
---

当用户重新打开应用或需要在后台服务重启后承接未完成的任务时，可以使用 `session: { kind: "resume" }` 恢复会话。

```ts
import {
  createCodingAgent,
  type CodingSessionStore,
  type CodingAgentFileCapabilities,
} from "@jai/coding-agent";

async function resumeExistingWork(
  sessionId: string,
  store: CodingSessionStore,
  fileCapabilities: CodingAgentFileCapabilities,
) {
  // 1. 指定已有会话 ID 重新建立连接
  const resumed = await createCodingAgent({
    model: "anthropic/claude-3-7-sonnet",
    cwd: fileCapabilities.workspaceDirectory,
    session: {
      kind: "resume",
      id: sessionId,
      store,
    },
    fileCapabilities,
  });

  if (resumed.isErr()) {
    // 针对不同恢复异常进行友好提示
    switch (resumed.error.code) {
      case "coding_sdk.session_not_found":
        console.error(`未在存储中找到会话: ${sessionId}`);
        break;
      case "coding_sdk.session_format_invalid":
        console.error("会话数据格式不兼容或版本过旧");
        break;
      default:
        console.error("恢复会话失败:", resumed.error.message);
    }
    return;
  }

  const agent = resumed.value;

  // 2. 验证历史记录是否已无缝恢复
  console.log("成功恢复会话，当前历史消息条数:", agent.state.messages.length);

  // 3. 继续推进后续对话
  await agent.prompt("接着上一次的进度，运行全量测试并告诉我结果");

  await agent.close();
}
```

## 关键要点

- **状态一致性**：恢复过程会自动回放该会话下的所有日志条目，包含先前的对话历史、上下文压缩摘要、扩展内部状态以及代码产物清单。
- **平滑继续**：恢复后的 Agent 实例与初次创建无异，支持全部控制方法（`prompt`、`steer`、`followUp`、`subscribe` 等）。
