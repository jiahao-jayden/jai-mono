---
title: 恢复 Session
description: 恢复已有 durable session，读取已持久化状态并继续同一上下文。
---

`resume` 只打开已存在的 session；不会为了方便而创建缺失 ID。

```ts
// @docs-compile
import { createCodingAgent } from "@jai/coding-agent";

const sessionId = "issue-482";
const resumed = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  cwd: ".",
  session: {
    kind: "resume",
    id: sessionId,
    directory: ".jai/sessions",
  },
});

if (resumed.isErr()) {
  if (resumed.error.code === "coding_sdk.session_not_found") {
    console.error(`找不到 Session：${sessionId}`);
  } else {
    console.error(resumed.error);
  }
} else {
  const agent = resumed.value;
  try {
    console.dir({
      messages: agent.state.messages,
      todos: agent.state.todos,
      artifacts: agent.state.artifacts,
    });
    const continued = await agent.prompt("继续上次分析，并列出下一步。");
    if (continued.isErr()) console.error(continued.error);
  } finally {
    const closed = await agent.close();
    if (closed.isErr()) console.error(closed.error);
  }
}
```

恢复后，messages、app state、Todos 和持久化的 Artifact catalog 都可从 `state` 读取。找不到时先让用户明确选择新 ID，再单独调用 `new`。
