---
title: Approval Flow
description: 用 requestApproval 将 SDK 权限请求映射到宿主自己的审批 UI 或策略。
---

权限 handler 是创建配置的一部分。它应尽快返回一个决定，并响应传入的 `AbortSignal`；不要把原始 SDK 对象直接通过 IPC 或事件总线转发。

```ts
// @docs-compile
import { createCodingAgent, type CodingPermissionRequest } from "@jai/coding-agent";

function decide(request: CodingPermissionRequest): "deny" | "allowOnce" | "alwaysAllow" {
  if (request.summary.risk === "high") return "deny";
  if (!request.canAlwaysAllow) return "allowOnce";
  return "deny";
}

const created = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  cwd: ".",
  permissionMode: "default",
  requestApproval: async (request, signal) => {
    if (signal?.aborted) return "deny";
    console.log({
      requestId: request.requestId,
      toolCallId: request.toolCallId,
      title: request.summary.title,
      risk: request.summary.risk,
    });
    return decide(request);
  },
});

if (created.isErr()) console.error(created.error);
else {
  const closed = await created.value.close();
  if (closed.isErr()) console.error(closed.error);
}
```

把 `requestId` 作为 pending approval 的 UI 主键，以 `toolCallId` 关联工具行。渲染 `summary`，而不是不加筛选地渲染 `args`；用户决定只投影为 `deny`、`allowOnce` 或 `alwaysAllow`。
