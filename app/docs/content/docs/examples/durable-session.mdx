---
title: 创建 Durable Session
description: 创建具名 durable session，处理重复 ID，并在运行结束后安全关闭 Agent。
---

`new` 创建一个可恢复的 session。Journal store 由宿主提供；同一 store 中重复 ID 会返回 `coding_sdk.session_exists`。

```ts
// @docs-compile
import { createCodingAgent, type CodingSessionStore } from "@jai/coding-agent";

declare const sessionStore: CodingSessionStore;

const created = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  cwd: ".",
  fileCapabilities: {
    homeDirectory: "/Users/alice",
    workspaceDirectory: "/workspace/repository",
    workspaceTrusted: true,
  },
  session: {
    kind: "new",
    id: "issue-482",
    store: sessionStore,
  },
  permissionMode: "plan",
  maxTurns: 20,
});

if (created.isErr()) {
  if (created.error.code === "coding_sdk.session_exists") {
    console.error('Session "issue-482" 已存在；请改用 resume 或选择新 ID。');
  } else {
    console.error(created.error);
  }
} else {
  const agent = created.value;
  try {
    const run = await agent.prompt("分析 issue 482 的可能原因并给出修复计划。");
    if (run.isErr()) console.error(run.error);
    else console.dir(run.value.state, { depth: null });
  } finally {
    const closed = await agent.close();
    if (closed.isErr()) console.error(closed.error);
  }
}
```

durable state 写入 Host 提供的 Session Journal store。SDK 不提供 session 列表或命名 API；产品负责索引、展示和清理，再在需要时传入 `resume`。

接着看 [恢复 Session](/docs/examples/resume-session)。
