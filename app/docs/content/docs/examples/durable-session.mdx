# 示例：持久会话

`new` / `resume` 需要 Host 提供两样东西：`store`（Session Journal 适配器）
和 `fileCapabilities`（本地配置根目录）。下面用 SDK 自带的工具函数搭一个
最小可用的内存 store 示意——**生产环境请实现真正的持久化后端**
（如 SQLite），内存 store 重启即丢。

```ts
import {
  createCodingAgent,
  emptyPersistedCodingSessionState,
} from "@jai/coding-agent";

// 示意：极简内存 store。CodingSessionStore 是 object 别名，
// SDK 只把它当不透明对象传给内部 journal 层。
const memoryRecords = new Map<string, unknown>();
const store = {
  // Host 按内部 journal 协议实现 load/create/append/delete…
};

const created = await createCodingAgent({
  model: "anthropic/claude-sonnet-4-5",
  cwd: "/path/to/project",
  session: {
    kind: "new",
    // id 可选，缺省 coding-<randomUUID()>
    store,
  },
  fileCapabilities: {
    homeDirectory: "/Users/you",          // 放 .jai/settings.json
    workspaceDirectory: "/path/to/project",
    workspaceTrusted: true,               // 允许项目级配置参与
  },
  requestApproval: async () => "deny", // 示例：默认拒绝，可换成真实 UI
});

if (created.isErr()) {
  // coding_sdk.file_capabilities_required：忘了传 fileCapabilities
  console.error(created.error.code, created.error.message);
  process.exit(1);
}
const agent = created.value;
console.log("sessionId:", agent.sessionId); // 下次 resume 用这个 id

await agent.prompt("初始化项目脚手架");
await agent.prompt("再补一个 README"); // 同一会话，上下文连续

await agent.close();
```

关键点：

- 缺 `fileCapabilities` 时创建直接失败，
  code `coding_sdk.file_capabilities_required`（phase `runtime_creation`），
  不是运行时才报错。
- `emptyPersistedCodingSessionState()` 可用于初始化一条空的持久化快照。
- 同一 `sessionId` 多次 `createCodingAgent({ session: { kind: "resume", id,
  store } })` 即可恢复（见下一节）。
