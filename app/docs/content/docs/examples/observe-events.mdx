---
title: 观察事件
description: 把 Agent streaming message、工具执行与 compaction 事件接入宿主 UI。
---

订阅应在运行前建立，并在宿主不再需要更新时取消。工具事件的 `toolCallId` 可用于关联 start、update 与 end；它不是错误 DTO 的字段。

```ts
// @docs-compile
import { createCodingAgent } from "@jai/coding-agent";

const created = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  cwd: ".",
  session: { kind: "ephemeral" },
});

if (created.isErr()) {
  console.error(created.error);
} else {
  const agent = created.value;
  const unsubscribe = agent.subscribe((event) => {
    switch (event.type) {
      case "message_update":
        if (event.assistantEvent.type === "text_delta") {
          console.log(event.assistantEvent.delta);
        }
        break;
      case "tool_execution_start":
        console.log("工具开始", event.toolCallId, event.toolName, event.title);
        break;
      case "tool_execution_end":
        console.log("工具结束", event.toolCallId, event.isError);
        break;
    }
  });
  try {
    const run = await agent.prompt("解释当前目录的架构，并报告你调用的工具。");
    if (run.isErr()) console.error(run.error);
  } finally {
    unsubscribe();
    const closed = await agent.close();
    if (closed.isErr()) console.error(closed.error);
  }
}
```

事件和 state 是 JSON-safe 投影，但内容仍可能包含路径、命令与模型输出。UI 层应继续根据当前用户和视图的权限投影最小字段。
