# 示例：临时 Agent

适合一次性任务：代码审查、单文件生成、快速问答。不需要 store，不需要
`fileCapabilities`，`close()` 后临时目录自动删除。

```ts
import { createCodingAgent } from "@jai/coding-agent";

async function reviewFile(path: string) {
  const created = await createCodingAgent({
    model: "anthropic/claude-sonnet-4-5",
    cwd: process.cwd(),
    permissionMode: "plan", // 只读：连审批都不需要，直接 deny 写操作
    // session 缺省 { kind: "ephemeral" }
  });
  if (created.isErr()) throw new Error(created.error.message);
  const agent = created.value;

  try {
    const result = await agent.prompt(
      `审查 ${path}，列出 bug 和改进点，只读不要写文件`
    );
    if (result.isErr()) throw new Error(result.error.message);
    const last = result.value.messages.at(-1);
    return last;
  } finally {
    await agent.close(); // 删除临时目录
  }
}
```

要点：

- `permissionMode: "plan"` 让 agent 只能读不能写，适合审查/分析类任务，
  省掉审批接线。
- ephemeral 会话的 `fileCapabilities` 由 SDK 自动生成为隔离临时目录，
  `workspaceTrusted: false`——项目级配置与扩展资源不参与。
- 多次 `prompt` 调用串行排队；临时 agent 用完一定 `close()`。
