---
title: Ephemeral Agent
description: 为一次性只读分析创建 ephemeral Agent，并在完成后关闭资源。
---

ephemeral session 适合不需要恢复的单次任务。SDK 在临时目录保存运行所需 session 数据，并在 `close()` 时删除。

```ts
// @docs-compile
import { createCodingAgent } from "@jai/coding-agent";

const created = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  cwd: ".",
  session: { kind: "ephemeral" },
  permissionMode: "plan",
  instructions: "只分析并给出计划，不修改文件。",
});

if (created.isErr()) {
  console.error(created.error);
} else {
  const agent = created.value;
  try {
    const run = await agent.prompt("评估当前项目主要模块的重构风险。");
    if (run.isErr()) console.error(run.error);
    else console.dir(run.value.messages, { depth: null });
  } finally {
    const closed = await agent.close();
    if (closed.isErr()) console.error(closed.error);
  }
}
```

`plan` 固定拒绝写入和可写 Bash，因此适合分析、审查和方案生成。进程崩溃或宿主没有调用 `close()` 时，不能承诺临时目录已经清理；把关闭动作纳入宿主自身的资源生命周期。
