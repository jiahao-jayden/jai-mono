SDK 的公开方法通过 `better-result` 的 `Result<T, CodingSdkError>` 返回结构化错误对象，提供机器可读的错误码、发生阶段与重试指示。

## `CodingSdkError` 结构

```ts
export interface CodingSdkError {
  readonly code: string;                // 唯一的结构化错误码（如 "coding_sdk.session_not_found"）
  readonly message: string;             // 人类可读的错误描述
  readonly retryable: boolean;          // 是否建议在短暂停顿后自动重试
  readonly phase: CodingSdkErrorPhase;  // 错误发生的生命周期阶段
}
```

### 9 个生命周期阶段（`phase`）

| 阶段（Phase） | 含义 |
|---|---|
| `runtime_creation` | 调用 `createCodingAgent` 时的初始化失败（配置非法、扩展激活失败、缺少必要参数） |
| `session` | 会话寻址、建立、恢复或反序列化失败 |
| `admission` | 用户输入预校验拦截（如提交了空 Prompt） |
| `model` | 模型名称解析失败、提供商服务不可用或流式请求超时 |
| `tool` | 工具执行抛出致命异常或输入格式非法 |
| `permission` | 权限策略解析异常或审批中断 |
| `compaction` | 上下文摘要生成失败或超出压缩阈值限制 |
| `navigation` | 会话分支跳转（`navigate`）失败 |
| `lifecycle` | 实例关闭后尝试调用操作等生命周期违规 |

:::tip 重试策略
当且仅当 `retryable: true` 时（通常发生在网络波动、供应商临时限流 429 或瞬态服务 5xx 故障的 `model` 阶段），调用方可采用指数退避算法进行重试；其他阶段的错误通常表示配置或参数存在确定性问题，重试无法解决。
:::

## 核心错误码速查

| 错误码（Code） | 阶段（Phase） | 触发原因与排查建议 |
|---|---|---|
| `coding_sdk.invalid_model_ref` | `model` | 模型字符串格式不合法，必须形如 `<provider>/<modelId>`。 |
| `coding_sdk.unsupported_provider` | `model` | 指定了未知的 Provider 前缀，目前仅支持 `anthropic`、`openai`、`openai-compatible`。 |
| `coding_sdk.model_unavailable` | `runtime_creation` | 模型配置校验失败或网络端点不可达。 |
| `coding_sdk.file_capabilities_required` | `runtime_creation` | 在持久化会话模式（`new` 或 `resume`）下未传入 `fileCapabilities`。 |
| `coding_sdk.invalid_tool_selection` | `runtime_creation` | `tools` 或 `excludeTools` 传入了不存在的内置工具名称。 |
| `coding_sdk.session_not_found` | `session` | 尝试恢复的 `sessionId` 在所指定的 Store 驱动中不存在。 |
| `coding_sdk.session_exists` | `session` | 在 `new` 模式下指定了已被占用的会话 ID。 |
| `coding_sdk.session_format_invalid` | `session` | 会话数据已损坏或协议版本与当前 SDK 不兼容。 |
| `coding_sdk.empty_prompt` | `admission` | `prompt()`、`steer()` 或 `followUp()` 传入了空字符串。 |
| `coding_sdk.agent_closed` | `lifecycle` | 在调用 `agent.close()` 之后尝试继续提交执行命令。 |

## 扩展错误体系（CodingExtensionError）

由自定义扩展在内部生命周期抛出的异常，会被自动封装为派生错误类并从 SDK 顶层导出：

- `CodingExtensionActivationFailed`：扩展在 `activate` 钩子中执行失败，导致整个 Agent 初始化终止。
- `CodingExtensionDeactivationFailed`：扩展在 `close` 时释放资源失败。
- `CodingExtensionHookFailed`：特定运行钩子（如 `beforeToolCall`）执行报错。
- `CodingExtensionPolicyBlocked`：扩展在 `beforeAgentStart` 钩子中主动拒绝并阻断了本轮执行。
- `CodingExtensionContractViolation`：扩展返回的数据不符合预定契约。
- `CodingExtensionOperationFailed`：通用扩展内部逻辑故障。
