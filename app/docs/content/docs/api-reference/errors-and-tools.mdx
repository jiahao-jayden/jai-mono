## `CodingSdkError`

```ts
interface CodingSdkError {
  code: string;
  message: string;
  retryable: boolean;
  phase: CodingSdkErrorPhase;
}
```

`phase` 是 `runtime_creation | session | admission | model | tool | permission | compaction | lifecycle`。错误 DTO 只包含安全、稳定的跨边界字段；不会携带 stack、cause、底层 SDK error、request ID、tool call ID 或未筛选 details。

## 权限 DTO

`CodingPermissionRequest` 包含 `requestId`、`sessionId`、`toolCallId`、`toolName`、JSON-safe `args`、`reason`、`canAlwaysAllow`、安全 `summary`、可选建议规则与 remember scope。决定值为：

```ts
type CodingPermissionDecision = "deny" | "allowOnce" | "alwaysAllow";
```

这里的关联 ID 只属于审批请求，不是 `CodingSdkError` 字段。跨进程时应再投影为 UI 所需的最小 DTO。

## 工具与状态项

`CodingToolName`：`Read | Bash | Edit | Write | UpdateTodos | SpawnAgent`。`fffind` 与 `ffgrep` 由 Search Extension 提供，不是内置工具名。

`CodingAgentTodo`：`id`、`content`、四态 `status`。

`CodingAgentArtifact`：`id`、`toolCallId`、`path`、`format: "markdown" | "html"`、`updatedAt`。

`CodingAttachment`：`id`、`filename`、`mimeType`、`size`、`sourcePath` 与可选 async `image()`。

行为语义见 [权限](/docs/guides/permissions)、[附件](/docs/guides/attachments) 和 [Todos 与 Artifacts](/docs/guides/todos-and-artifacts)。
