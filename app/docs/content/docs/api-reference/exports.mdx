`@jai/coding-agent` 的所有对外公开能力均通过其根模块具名导出。

## 核心函数与构造类

| 导出名称 | 分类 | 用途说明 |
|---|---|---|
| `createCodingAgent` | 函数 | 创建并初始化 Agent 实例的唯一主入口 |
| `defineExtension` | 函数 | 声明类型安全的 Agent 扩展定义 |
| `resolveSdkModel` | 函数 | 静态解析并校验模型标识字符串（`<provider>/<model>`） |
| `generateSessionTitle` | 函数 | 使用模型从用户首条消息中生成简短会话标题 |
| `createPermissionApprovalQueue` | 函数 | 创建跨调用共享的人工审批先进先出（FIFO）队列 |
| `createBackgroundAgentStore` | 函数 | 创建跨调用共享的后台任务管理器 |
| `BackgroundAgentStore` | 类 | 后台异步 Shell 作业管理器类 |
| `InMemorySessionStore` | 类 | 内存级会话持久化存储参考实现，适合测试与开发调试 |
| `CodingAgentTelemetryObserver` | 类 | 统一链路追踪与 Span 遥测观察器 |
| `codingArtifactsFromAppState` | 函数 | 从持久化 AppState 反序列化并排序产物目录 |
| `redactCommand` | 函数 | 对 Shell 命令行中的凭据与敏感字段进行掩码脱敏 |
| `emptyPersistedCodingSessionState` | 函数 | 构造初始状态的持久化快照骨架 |

---

## 核心接口与数据类型

### 实例与执行
- `CodingAgent`：Agent 运行时实例接口。
- `CodingAgentCreateOptions`：`createCodingAgent` 接受的完整入参配置。
- `CodingPromptOptions`：单次 `prompt` 的执行选项（包含附件）。
- `CodingRunResult`：单次运行结束后的完整执行结果与最终状态。
- `CodingQueuedInput`：排队待执行的用户指令输入对象。

### 会话与存储
- `CodingSessionSelection`：会话生命周期模式选择（`ephemeral`、`new`、`resume`）。
- `CodingSessionStore`：持久化存储适配器抽象接口。
- `CodingAgentFileCapabilities`：本地工作区与用户目录权责声明。
- `SessionConflictError`：并发版本冲突异常。

### 事件与状态
- `CodingAgentEvent`：包含 15 种生命周期、Token 增量、工具状态与压缩通知的联合事件类型。
- `CodingAgentState`：不可变的状态快照。
- `CodingAgentMessage`：纯净的标准消息格式（包含 `user`、`assistant`、`tool`）。
- `CodingContextMeasurement`：上下文各成分 Token 占用预估测量。
- `CodingAgentArtifact`：工程生成的技术方案或代码产物。

### 权限与安全
- `CodingPermissionMode`：四档权限模式（`"ask"`、`"allow"`、`"auto"`、`"plan"`）。
- `CodingPermissionRequest`：传递给审批回调的详细操作上下文与风险评估。
- `CodingPermissionDecision`：审批决策（`"deny"`、`"allowOnce"`、`"alwaysAllow"`）。
- `CodingApprovalHandler`：异步审批回调函数签名。
- `SessionAllowRules`：跨轮次持久化授权记忆规则表。

### 错误定义
- `CodingSdkError`：统一错误对象接口。
- `CodingSdkErrorPhase`：9 个生命周期错误阶段联合类型。
- `CodingExtensionError` 及相关派生错误类（如 `CodingExtensionActivationFailed`、`CodingExtensionHookFailed`）。
