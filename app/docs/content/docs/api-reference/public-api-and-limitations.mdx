---
title: 公开 API 与限制
description: 核对稳定 root exports、禁止的 deep import 与公开 SDK 的产品边界。
---

`@jai/coding-agent` 只提供一个正式入口：

- `@jai/coding-agent`：创建 Agent、读取 artifact、定义 Extension，以及所有公开类型。

## Root value exports

- `createCodingAgent`
- `codingArtifactsFromAppState`
- `defineExtension`

Root 还稳定导出 `CodingAgentCreateOptions`、`CodingProviderOptions`、session、prompt、state/event、permission、attachment、Todo/Artifact、extension、JSON 与 error DTO 类型。准确字段见本节的 API Reference 页面。

## Import 边界

只从 package root 导入。不要 deep import `dist`、`src` 或其他未记录路径；这些实现不属于公开契约，升级时可能变化。

## 产品边界

公开 SDK 不包含 Jai config、模型 catalog、插件目录发现、Connector client、Desktop UI 或 CLI session 列表。Desktop 与 CLI 分别持有这些产品业务，并把最终的模型、扩展和审批策略传给 SDK。

SDK 的 Extension 公开能力是 tools、skills、hooks 和释放逻辑；没有公开的 `mcpServers` capability。Jai Agent Plugin 的发现与其 MCP 描述的适配发生在 `@jai/extension` 和具体宿主中，再以普通 Extension tools 传入 SDK。
