## `CodingAgentCreateInput`

```ts
interface CodingAgentCreateInput {
  workspace: CodingWorkspace;
  session: SessionSelection;
  resolveModel: CodingModelResolver;
  requestApproval?: CodingApprovalHandler;
  homeDirectory?: string;
  plugins?: CodingPluginOptions;
  connector?: CodingConnectorIntegration;
  execution?: CodingAgentExecutionConfiguration;
}
```

`workspace` 字段中 `cwd` 必需，可选 `configRoot`、`defaultAllowedDirectories`、`localFileAccess` 与 `trusted`。

`homeDirectory` 控制用户级配置根，默认使用 OS home。

`resolveModel({ model, settings })` 返回 `{ model, provider }`。`requestApproval(request, signal?)` 在权限规则要求询问时返回拒绝、单次允许或持久允许。

## `CodingAgentExecutionConfiguration`

```ts
interface CodingAgentExecutionConfiguration {
  model?: string;
  permissionMode?: "default" | "acceptEdits" | "plan" | "dontAsk" | "bypassPermissions";
  maxTurns?: number;
  instructions?: string;
  compactionSummaryInstructions?: string;
}
```

## `SessionSelection`

```ts
type SessionSelection =
  | { kind: "new"; id?: string; directory: string }
  | { kind: "resume"; id: string; directory: string }
  | { kind: "ephemeral" };
```

`new` 与 `resume` 将 `directory` 作为持久会话目录；`ephemeral` 使用 SDK 创建并在 `close()` 时删除的临时目录。

Plugin 与 connector 配置详见 [工具与动态能力](/docs/guides/tools-and-capabilities)。
