## `CodingAgentCreateOptions`

```ts
interface CodingAgentCreateOptions {
  model: string;
  provider?: CodingProviderOptions;
  extensions?: readonly CodingAgentExtension[];
  extensionRuntime?: CodingExtensionRuntimeAdapter;
  cwd?: string;
  session?: CodingSessionSelection;
  permissionMode?: CodingPermissionMode;
  maxTurns?: number;
  instructions?: string;
  compactionSummaryInstructions?: string;
  requestApproval?: CodingApprovalHandler;
  tools?: readonly CodingToolName[];
  excludeTools?: readonly CodingToolName[];
}
```

`model` 是 `<provider>/<model>`，其中 provider 只能是 `anthropic`、`openai` 或 `openai-compatible`。`cwd` 默认是 `process.cwd()`；省略 `session` 时默认 ephemeral。

## Provider

```ts
interface CodingProviderOptions {
  apiKey?: string;
  baseUrl?: string;
  headers?: Readonly<Record<string, string>>;
  authentication?: "bearer" | "x-api-key" | "none";
}
```

未传 `apiKey` 时，Anthropic 读取 `ANTHROPIC_API_KEY`，OpenAI 与 OpenAI-compatible 读取 `OPENAI_API_KEY`。Anthropic 仅支持 `x-api-key`；另外两种 provider 支持 `bearer` 和 `none`。`baseUrl` 仅允许 HTTPS 或无 userinfo 的 loopback HTTP。

## Session

```ts
type CodingSessionSelection =
  | { kind: "new"; id?: string; directory: string }
  | { kind: "resume"; id: string; directory: string }
  | { kind: "ephemeral" };
```

`new` 与 `resume` 要求调用方提供 durable session 的目录。session 的目录布局和列表策略属于宿主，不是 SDK public API。

## Extensions

`CodingAgentExtension` 必须声明稳定 `id`；初始化 context 提供 `sessionId`、`cwd`、
`permissionMode`，以及该 Extension 声明的 configuration store。它可返回 `tools`、`skills`、
`hooks` 和 `dispose()`。更多字段与约束见 [工具与动态能力](/docs/guides/tools-and-capabilities)。

`extensionRuntime` 是宿主为 Extension configuration 与 Extension-owned approval 提供的 adapter。
普通嵌入只需使用 core-owned tools，不需要传它；需要持久化 Extension configuration 或由
Extension 自己处理授权时，宿主必须显式提供对应读写与审批能力。`allow` 类型的永久决策在
没有持久化 adapter 时会 fail closed。
