`createCodingAgent` 是 SDK 的唯一主入口，用于配置并实例化一个 Coding Agent 运行时。

## 函数签名

```ts
export async function createCodingAgent<TAppState extends JsonObject = JsonObject>(
  input: CodingAgentCreateOptions,
): Promise<Result<CodingAgent<TAppState>, CodingSdkError>>
```

- **`TAppState`**：泛型参数，允许宿主挂载自定义的应用状态模型（默认为 `JsonObject`）。
- **返回值**：`Promise<Result<CodingAgent<TAppState>, CodingSdkError>>`。成功时 `result.value` 包含可操作的 Agent 实例；失败时 `result.error` 包含标准错误对象（错误阶段为 `runtime_creation`）。

---

## 核心配置选项

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|:---:|---|
| `model` | `string` | **必填** | 模型引用标识，格式为 `"<provider>/<modelId>"`。支持 `anthropic`、`openai` 与 `openai-compatible`。 |
| `cwd` | `string` | 可选 | 绑定的工作目录绝对路径。内置工具的文件读写与 Shell 命令均在此目录下执行。缺省为 `process.cwd()`。 |
| `provider` | `CodingProviderOptions` | 可选 | 自定义 Provider 配置，包含 `apiKey`、`baseUrl`、自定义 `headers` 与 `idleTimeoutMs`。 |
| `instructions` | `string` | 可选 | 附加的系统提示词（追加于默认工程系统提示词之后）。 |
| `session` | `CodingSessionSelection` | 可选 | 会话模式：`ephemeral`（默认内存会话）、`new`（新建持久会话）或 `resume`（恢复已有会话）。 |
| `permissionMode` | `CodingPermissionMode` | 可选 | 全局权限模式：`"ask"`（默认）、`"allow"`、`"auto"` 或 `"plan"`。 |
| `requestApproval` | `CodingApprovalHandler` | 可选 | 异步审批回调函数：当命中需要人工确认的高危或未知操作时调用。 |
| `tools` | `readonly CodingToolName[]` | 可选 | 内置工具白名单。若指定，则仅激活列表中的内置工具。可选值：`"Read" \| "Bash" \| "Edit" \| "Write"`。 |
| `excludeTools` | `readonly CodingToolName[]` | 可选 | 内置工具黑名单。与 `tools` 重叠时，排除规则优先。 |
| `extensions` | `readonly CodingAgentExtension[]` | 可选 | 装配自定义或官方扩展插件列表。SDK 内部会校验每个扩展的 `id` 唯一性。 |
| `maxTurns` | `number` | 可选 | 单次任务执行允许的最大往返交互轮次。默认无硬性限制。 |

## 高级会话与持久化参数

用于接入企业级存储或复杂环境上下文：

| 字段 | 类型 | 说明 |
|---|---|---|
| `fileCapabilities` | `CodingAgentFileCapabilities` | 包含 `homeDirectory`、`workspaceDirectory` 与 `workspaceTrusted`。在使用 `new` 或 `resume` 会话时**必选**。 |
| `sessionAllowRules` | `SessionAllowRules` | 宿主持有的跨调用授权记忆表，用于免除已选择“总是允许”的重复确认。 |
| `sessionGrantWorkspaceRoot` | `string` | 绑定到会话授权记忆表的工作区根路径。 |
| `approvalQueue` | `PermissionApprovalQueue` | 跨调用共享的人工审批先进先出（FIFO）队列，保证界面弹窗有序单发。 |
| `backgroundAgents` | `BackgroundAgentStore` | 跨轮次共享的后台任务注册表，用于托管异步 Shell 进程。 |
| `autoCompaction` | `boolean` | 是否开启上下文自动压缩，默认为 `true`。 |
| `compactionSummaryInstructions` | `string` | 自动压缩时要求模型生成摘要的偏好指令。 |

## 观测与扩展旁路

| 字段 | 类型 | 说明 |
|---|---|---|
| `permissionTelemetryObserver` | `PermissionTelemetryObserver` | 仅观察权限求值结果与审批决策的旁路监听器，不参与流程干预。 |
| `modelRequestTelemetryObserver` | `ModelRequestObserver` | 在模型请求组装完毕、向外部网络发送前观察完整上下文的旁路监听器。 |
| `extensionRuntime` | `CodingExtensionRuntimeAdapter` | 为扩展插件提供宿主级环境交互（配置存取、诊断上报）的适配接口。 |
| `protectConfigDirectories` | `boolean` | 默认 `false`。开启后将严格保护工作区与家目录下的 `.jai/` 配置目录免受内置工具修改。 |
| `hookTimeoutMs` | `number` | 阻塞型扩展钩子（如 `beforeAgentStart`）的执行超时上限（毫秒，默认 30,000）。 |
