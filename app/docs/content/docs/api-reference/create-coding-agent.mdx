```ts
function createCodingAgent<TAppState extends JsonObject = JsonObject>(
  input: CodingAgentCreateInput,
): Promise<Result<CodingAgent<TAppState>, CodingSdkError>>;
```

## 输入

`CodingAgentCreateInput`：

- `workspace: CodingWorkspace`：工作目录与本地文件访问配置。
- `session: SessionSelection`：`new`、`resume` 或 `ephemeral`。
- `resolveModel: CodingModelResolver`：将模型请求解析为 runtime Model 与 Provider。
- `requestApproval?`、`homeDirectory?`、`plugins?`、`connector?`：可选集成配置。
- `execution?: CodingAgentExecutionConfiguration`：model、permission mode、turn 数与 instructions。

创建阶段会解析 session、配置、模型、MCP/plugin 能力与 runtime。任何可恢复失败都返回 `Err<CodingSdkError>`；不要用 try/catch 代替 Result 分支。

```ts
import { createCodingAgent, type CodingModelResolver, type JsonObject } from "@jai/coding-agent";

type MyAppState = JsonObject & { readonly activeView?: string };

async function openDurableAgent(resolveModel: CodingModelResolver) {
  const cwd = process.cwd();
  const created = await createCodingAgent<MyAppState>({
    workspace: { cwd, configRoot: cwd },
    session: { kind: "new", directory: `${cwd}/.jai/sessions` },
    resolveModel,
    execution: { maxTurns: 30, permissionMode: "default" },
  });

  if (created.isErr()) console.error(created.error);
  return created;
}
```

## 创建约束

- `new` 若 ID 已存在则失败。
- `resume` 若 ID 不存在则失败。
- `ephemeral` 创建临时存储，并由 `close()` 删除。
- `execution.instructions` 追加到 SDK 默认 coding instructions。
- `compactionSummaryInstructions` 只配置 compaction summary。

参见 [创建配置](/docs/api-reference/host-and-configuration)。
