```ts
function createCodingAgent<TAppState extends JsonObject = JsonObject>(
  options: CodingAgentCreateOptions,
): Promise<Result<CodingAgent<TAppState>, CodingSdkError>>;
```

创建阶段会校验 session 和工具选择，验证静态 Extension capability、activate 每-session instance 并建立模型与 runtime。可恢复失败返回 `Err<CodingSdkError>`；处理 `Result`，不要用 try/catch 替代正常错误分支。

```ts
import { createCodingAgent, type CodingSessionStore, type JsonObject } from "@jai/coding-agent";

type MyAppState = JsonObject & { readonly activeView?: string };
declare const sessionStore: CodingSessionStore;

const created = await createCodingAgent<MyAppState>({
  model: "anthropic/claude-sonnet-4-20250514",
  cwd: process.cwd(),
  fileCapabilities: {
    homeDirectory: process.env.HOME ?? process.cwd(),
    workspaceDirectory: process.cwd(),
    workspaceTrusted: true,
  },
  session: { kind: "new", store: sessionStore },
  permissionMode: "default",
  maxTurns: 30,
});

if (created.isErr()) console.error(created.error);
```

## 创建约束

- `new` 若 ID 已存在则失败。
- `resume` 若 ID 不存在则失败。
- `ephemeral` 使用临时存储，并由 `close()` 删除。
- persistent session 必须由 Host 提供 `fileCapabilities`；其 user/workspace JSON 与 Skills 只从这些根读取。
- `instructions` 追加到 SDK 默认 coding instructions。
- `compactionSummaryInstructions` 只配置 compaction summary。
- `tools` 只启用列出的内置工具；`excludeTools` 最后应用，重叠时排除优先。

详见 [创建配置](/docs/api-reference/host-and-configuration) 与 [工具与动态能力](/docs/guides/tools-and-capabilities)。
