```ts
interface CodingAgent<TAppState extends JsonObject = JsonObject> {
  readonly sessionId: string;
  readonly state: CodingAgentState<TAppState>;
  prompt(prompt: string, options?: CodingPromptOptions): Promise<Result<CodingRunResult<TAppState>, CodingSdkError>>;
  steer(prompt: string): Promise<Result<void, CodingSdkError>>;
  followUp(prompt: string): Promise<Result<void, CodingSdkError>>;
  waitForIdle(): Promise<Result<void, CodingSdkError>>;
  generateTitle(firstMessage: string): Promise<Result<string, CodingSdkError>>;
  abort(): Promise<Result<void, CodingSdkError>>;
  subscribe(listener: (event: CodingAgentEvent) => void): () => void;
  close(): Promise<Result<void, CodingSdkError>>;
}
```

## 运行与控制

- `prompt(text, options?)`：提交一次完整运行；附件通过 `options.attachments` 提供。
- `steer(text)`：在当前运行中发送优先处理的文字指令。
- `followUp(text)`：把文字加入当前运行后的队列。
- `abort()`：请求取消当前运行。
- `waitForIdle()`：等待已经接纳的工作结束。
- `generateTitle(firstMessage)`：生成短标题。

`prompt`、`steer` 与 `followUp` 都拒绝空白字符串。多个 prompt 由 SDK 串行化；不要在宿主侧基于 state 手工管理队列。

## 状态与释放

`sessionId` 在 Agent 生命周期内稳定。`state` 是快照；`appState` 经过 clone，不能通过引用修改 SDK 状态。`subscribe()` 返回取消订阅函数；`close()` 关闭 Agent 并释放 session/runtime 资源。关闭后再调用运行或控制方法会返回 lifecycle error。

参见 [Prompts 与控制](/docs/concepts/prompts-and-control) 与 [State 与 Events API](/docs/api-reference/state-and-events)。
