`CodingAgent` 接口是 Agent 运行时的主要交互把手。所有涉及异步控制的方法均统一返回 `Promise<Result<T, CodingSdkError>>`。

```ts
export interface CodingAgent<TAppState extends JsonObject = JsonObject> {
  readonly sessionId: string;
  readonly state: CodingAgentState<TAppState>;

  prompt(prompt: string, options?: CodingPromptOptions): Promise<Result<CodingRunResult<TAppState>, CodingSdkError>>;
  advance(inputs?: readonly CodingQueuedInput[]): Promise<Result<CodingRunResult<TAppState>, CodingSdkError>>;
  steer(input: string | CodingQueuedInput): Promise<Result<void, CodingSdkError>>;
  followUp(input: string | CodingQueuedInput): Promise<Result<void, CodingSdkError>>;
  waitForIdle(): Promise<Result<void, CodingSdkError>>;
  navigate(entryId: string): Promise<Result<void, CodingSdkError>>;
  compact(signal?: AbortSignal): Promise<Result<void, CodingSdkError>>;
  generateTitle(firstMessage: string): Promise<Result<string, CodingSdkError>>;
  abort(): Promise<Result<void, CodingSdkError>>;
  stopBackgroundAgent(toolCallId: string): Promise<Result<{ readonly stopped: boolean }, CodingSdkError>>;
  subscribe(listener: (event: CodingAgentEvent) => void): () => void;
  close(): Promise<Result<void, CodingSdkError>>;
}
```

---

## 属性列表

### `sessionId`
`string`。当前会话的唯一标识符。

### `state`
`CodingAgentState<TAppState>`。当前会话的只读状态投影快照，每次访问均实时计算：
- `status`：`"idle"` \| `"running"` \| `"aborted"` \| `"closed"`
- `messages`：包含本会话历史全部对话条目的只读数组
- `artifacts`：会话中生成或修改的代码文件产物清单
- `appState`：宿主自定义挂载的应用状态
- `extensions`：扩展命名空间内部的只读状态集合

---

## 核心方法

### `prompt(prompt, options?)`
提交一条新的用户提示词并驱动 Agent 运行至本次执行结束。
- 若入参仅包含空白字符，将直接返回 `coding_sdk.empty_prompt` 错误。
- 多个并发 `prompt` 调用会自动在内部排队，按提交顺序串行执行。
- `options.attachments`：可选的附件列表（包含本地图片或参考文件）。

### `steer(input)`
在 Agent 执行期间进行**插队纠偏**。立即向内部循环注入一条高优先级指令，打断后续计划并调整执行方向。

### `followUp(input)`
向就绪队列中追加一条后续任务。当前整轮运行彻底结束后，Agent 会自动提取并开始执行此输入。

### `abort()`
请求主动取消当前正在执行的任务轮次。

### `waitForIdle()`
返回一个 Promise，等待当前所有排队的任务与工具彻底结束并回归 `idle` 状态。

### `compact(signal?)`
在 Agent 处于空闲状态时，立即对当前分支的上下文执行一次摘要压缩。

### `generateTitle(firstMessage)`
基于首条用户消息与模型初始回答，调用当前模型快速生成一段不超过 8 个词的精炼会话标题。

### `stopBackgroundAgent(toolCallId)`
根据工具调用 ID 主动终止一个正在后台运行的异步 Shell 作业。

### `subscribe(listener)`
注册同步事件监听函数，实时捕获流式文本增量（`text_delta`）、思考过程（`thinking_delta`）、工具进度与生命周期变更。返回注销监听函数。

### `close()`
优雅销毁 Agent 实例：
1. 取消正在执行的作业；
2. 等待未落盘的日志完成持久化；
3. 逆序调用并释放已激活的扩展插件（`deactivate`）；
4. 如果是临时会话（`ephemeral`），清理本地临时工作目录。
- 重复调用 `close()` 是安全的（幂等返回成功）。
