`@jai/coding-agent` 是面向 Node.js 与 TypeScript 环境的 Coding Agent SDK。它封装了完整的 Agent 执行循环、内置工程工具（Read、Bash、Edit、Write）、基于 AST 的安全权限审批、分支会话持久化与上下文压缩，对外提供类型安全且纯净的事件与状态 DTO。

Desktop 桌面端、无头 `jai` CLI 与自动化评测 Harness 均基于此 SDK 构建。宿主只负责各自的 UI 渲染、交互输入与配置加载，核心执行与状态管理均由 SDK 驱动。

## 分层架构

```text
你的应用（Host）
        │  createCodingAgent({ model, provider, cwd, session, ... })
        ▼
@jai/coding-agent      公开 SDK：Agent 生命周期、权限、会话、扩展与事件状态 DTO
        │
        ▼
@jai/agent             执行引擎：Agent loop、harness、hooks、compaction、journal
        │
        ▼
@jai/ai                模型适配层：provider-neutral 流式协议与多厂商适配
        │
        ▼
Anthropic / OpenAI / OpenAI-compatible 服务端
```

- **类型安全与纯净边界**：SDK 导出的 API 经过严格封装。内部引擎（`@jai/agent`）与模型抽象（`@jai/ai`）的内部类型均被投影为以 `Coding*` 为前缀的 DTO（如 `CodingAgentEvent`、`CodingAgentState`），外部调用方不会直接接触到底层实现细节。
- **配置权归属宿主**：本地配置文件解析（如 `~/.jai/settings.json`）、模型厂商目录匹配与凭据获取由宿主应用负责，SDK 只接收结构化、显式的配置参数。
- **模块化扩展支持**：官方扩展（如连接器、MCP、技能库、网页搜索、任务清单、子 Agent）均以声明式 `CodingAgentExtension` 对象的形式，通过 `extensions` 配置装配。

## 核心能力

| 能力模块 | 调用方式 | 说明 |
|---|---|---|
| 创建 Agent | `createCodingAgent({ model: "anthropic/claude-3-7-sonnet" })` | 初始化 Agent 实例，返回统一 Result |
| 交互执行 | `agent.prompt("...")` | 提交任务提示词并运行至终态 |
| 实时事件 | `agent.subscribe((event) => ...)` | 订阅 15 种生命周期、流式文本与工具执行事件 |
| 会话管理 | `session: { kind: "ephemeral" \| "new" \| "resume" }` | 支持临时会话与基于持久化 Journal 的多轮会话 |
| 权限审批 | `permissionMode: "ask" \| "allow" \| "auto" \| "plan"` | 细粒度权限控制与交互式审批回调 `requestApproval` |
| 内置工具 | `Read`、`Bash`、`Edit`、`Write` | 开箱即用的工程操作工具，支持白名单与黑名单裁剪 |
| 功能扩展 | `defineExtension({ id, tools, hooks, ... })` | 声明自定义工具、生命周期 Hooks 与动态工具目录 |
| 后台任务 | Bash `runInBackground` + `BackgroundAgentStore` | 异步执行耗时任务，不阻塞前台对话 |
| 观测遥测 | `CodingAgentTelemetryObserver` | 提供标准链路追踪与耗时 Span 采集 |
