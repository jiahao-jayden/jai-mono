`@jai/coding-agent` 是面向 Node.js 宿主的公开 SDK。它负责 Agent 执行循环、内置 coding tools、会话、权限求值、状态和事件投影；Desktop、CLI 等产品自己的配置、模型目录、插件发现与 UI 留在各自宿主中。

## 从这里开始

- [SDK 概览](/docs/quickstart/overview)：理解 SDK 与宿主的职责边界。
- [安装](/docs/quickstart/installation)：准备 Node.js 项目和模型凭据。
- [创建第一个 Agent](/docs/quickstart/create-your-first-agent)：以只读方式运行一次 prompt。

## 核心 API

```ts
import { createCodingAgent } from "@jai/coding-agent";

const created = await createCodingAgent({
  model: "openai/gpt-4.1-mini",
  cwd: process.cwd(),
  session: { kind: "ephemeral" },
  permissionMode: "plan",
});
```

创建、运行和关闭都返回 `better-result` 的 `Result`。先处理 `isErr()`，再读取 `value`；不要把预期的 SDK 失败改为异常控制流。

模型字符串使用 `<provider>/<model>` 格式。内置 provider 是 `anthropic`、`openai` 和 `openai-compatible`；默认分别读取 `ANTHROPIC_API_KEY` 或 `OPENAI_API_KEY`。自定义 endpoint 与认证方式通过 `provider` 配置。
