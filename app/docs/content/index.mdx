## Jai Coding Agent

`@jai/coding-agent` 是 Jai 的公开 Coding Agent SDK。Desktop、CLI 与 WorkBuddy 使用同一套 Agent、Session、权限与工具语义；宿主只提供模型、workspace、session 存储与人工授权等外部 authority。

## 从这里开始

- [SDK](/sdk)：在自己的宿主中创建并使用 Coding Agent。
- [CLI](/cli)：在终端交互，或用 `jai -p` 自动化运行。
- [WorkBuddy Benchmark](/workbuddy-bench)：用普通 CLI 跑 WorkBuddy 的所有测试集。

:::tip
首版文档只覆盖已经实现或已经稳定的公开契约。Desktop 内部迁移资料和架构草案不会作为公开 API 承诺发布。
:::
