# Jai Coding Agent SDK

`@jai/coding-agent` 是 jai-mono 的公开 SDK：在你的 TypeScript 应用里创建、
运行和管理 coding agent。它提供 Agent 生命周期、内置工具（Read / Bash /
Edit / Write）、权限审批、会话持久化、扩展机制，以及 JSON 安全的事件、
状态与错误 DTO。

Desktop 应用、headless `jai` CLI、WorkBuddy 评测 harness 都通过这个 SDK
运行 Agent——它们只负责各自的 UI / TTY / subprocess 宿主层，不复制 Agent
loop、工具、权限或 session runtime。

## 分层架构

```text
你的应用（Host）
        │  createCodingAgent({ model, provider, cwd, session, ... })
        v
@jai/coding-agent      公开 SDK：Agent 创建、权限、会话、扩展、事件/状态 DTO
        │
        v
@jai/agent             内部：agent loop、harness、hooks、compaction、durable session
        │
        v
@jai/ai                内部：provider-neutral 消息、流式事件、模型注册表
        │
        v
Anthropic / OpenAI / OpenAI-compatible API
```

关键边界（代码事实）：

- SDK 公开 API **严格等于 `src/sdk.ts` 的具名导出**——没有 `export *`。
  `@jai/ai` 的 `Provider` / `Message`、`@jai/agent` 的 `Agent` 等底层类型
  **没有被 re-export**，SDK 消费者 import 不到。SDK 用 `Coding*` 前缀的投影
  类型（如 `CodingAgentEvent`、`CodingAgentState`）重新包装了它们。
- Jai 产品级默认配置（用户/项目配置、provider 目录、插件发现、数据目录约定）
  **不在 SDK 里**，由各产品宿主（Desktop / CLI / WorkBuddy）各自实现。
  SDK 只接收 Host 传进来的显式参数。
- `@jai/extension` 提供官方扩展（connector、agent-plugins、skills、
  web-search、todo、subagent 等），以 `CodingAgentExtension` 纯数据对象的形式
  经 `extensions` 选项装配进 SDK。

## 能力一览

| 能力 | 入口 |
|---|---|
| 创建 Agent | `createCodingAgent({ model: "anthropic/claude-..." })` |
| 运行一轮 | `agent.prompt("...")` → `Result<CodingRunResult>` |
| 实时事件 | `agent.subscribe((event) => ...)`（15 种事件） |
| 会话 | `ephemeral`（缺省）/ `new` / `resume` |
| 权限审批 | `permissionMode: "ask" \| "allow" \| "auto" \| "plan"` + `requestApproval` 回调 |
| 内置工具 | `Read`、`Bash`、`Edit`、`Write`（可白名单/黑名单裁剪） |
| 扩展 | `defineExtension({ id, tools, hooks, catalogs, ... })` |
| 后台执行 | Bash `runInBackground` + `BackgroundAgentStore` |
| 可观测 | `CodingAgentTelemetryObserver`（span：`jai.run → jai.turn → …`） |
| 错误 | `CodingSdkError { code, message, retryable, phase }`（9 个 phase） |
