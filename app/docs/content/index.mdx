`@jai/coding-agent` 是用于把 Coding Agent 嵌入 CLI、桌面应用、服务端任务和开发者工具的 TypeScript SDK。它负责模型工具循环、会话状态和事件；你的应用提供模型连接、工作目录、会话目录及用户授权。

如果你是第一次接触 Jai，从 [安装](/docs/quickstart/installation) 开始。五分钟内，你会运行一个真实的 OpenAI 请求，让 Agent 以只读 `plan` 模式读取当前项目的 `README` 并输出总结，同时正确处理 `Result` 和关闭资源。

适合以下场景：

- 在 TypeScript 产品中加入代码库问答、分析或修改能力。
- 创建可恢复的长任务，并把进度、工具调用和产物投影到产品 UI。
- 由宿主统一控制模型凭据、文件边界、权限审批和 session 存储。

## SDK 边界

- root import：`@jai/coding-agent`
- 宿主装配：`CodingAgentHost`
- 正常可恢复失败：`Result<T, CodingSdkError>`
- 会话：`new`、`resume`、`ephemeral`
- 内置工具：`Read`、`Write`、`Edit`、`Glob`、`Grep`、`Bash`、`Skill`、`UpdateTodos`、`SpawnAgent`

日常集成从 root import `@jai/coding-agent`。`@jai/coding-agent/jai-host` 是同一 package 提供的可选高层宿主配置能力，适合需要 Jai 标准配置、模型目录和 session 布局的 Advanced/Integration 场景。

深入集成时，请继续阅读 [Prompt 与运行控制](/docs/concepts/prompts-and-control)、[State 与 Events](/docs/concepts/state-and-events)、[CodingAgent API](/docs/api-reference/coding-agent)、[Errors 与 Tools](/docs/api-reference/errors-and-tools) 和 [公开 API 与当前限制](/docs/api-reference/public-api-and-limitations)。
