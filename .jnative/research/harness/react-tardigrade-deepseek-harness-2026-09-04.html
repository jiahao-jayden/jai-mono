直接结论

不要把同名的 Effect 或「可逆」当作同一语义

  1. 结论 01

    React 可迁移的核心是纯推导、受控提交、外部执行分相；不是组件树或 JSX。

  2. 结论 02

    Tardigrade 将纯推导接到 immutable log 与 keyed transition，形成 at-least-once 的 durable execution。

    查看来源

  3. 结论 03

    DSH 的 reversible effects 指插件注册与资源的卸载清理，而非工具、副作用或会话历史的通用回滚。

    查看来源

  4. 结论 04

    对 result 缺失，Tardigrade 默认重驱；DSH 标记 unknown 并要求幂等、核验或人工处理。

  5. 结论 05

    JAI 应吸收 React 的分相和 Tardigrade 的动作 identity，但保持当前未知工具结果停驻的保守边界。

共同原则与发生分歧的边界

对 JAI 的设计取舍

借鉴来源应吸收不应外推
React纯 projection、最小事实、单一 owner、显式状态/identity。Effect cleanup 不能当作工具 undo；React key 不是 durable idempotency key。
Tardigrade将允许恢复的 action 从 durable evidence 纯地派生，并明确 action identity/完成判据。不默认采用 at-least-once 重跑，也不为交互式 Session 预建 actor graph。
DeepSeek Harness将 extension/connector 的注册、资源与 teardown 作为独立 lifecycle contract。插件卸载不等于撤销 journal 或外部工具的已发生影响。

对本项目的影响

保持 JAI 的 journal / Runtime Host / ACP 分层。近期可把 recovery verdict 收紧为“由 durable facts 推导的 action 白名单”，并在 extension/connector 领域独立审计注册与 teardown。未知 tool outcome 继续停驻，除非下游有可核验的幂等或对账契约。

尚未确认

JAI 每个 provider/tool 的幂等键、读后校验与补偿能力；以及 DSH 的 Cordis lifecycle 与 JAI extension/connector 的具体映射。在这些事实明确前，不扩大自动重试。
